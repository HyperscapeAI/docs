## Overview

Hyperscape captures game music and sound effects in RTMP streams using PulseAudio virtual sinks. This allows viewers to hear in-game audio on Twitch, Kick, and X/Twitter streams.

## Architecture

```
Game (Chrome) → PulseAudio Virtual Sink → Monitor → FFmpeg → RTMP
```

**Flow:**
1. Chrome outputs audio to PulseAudio virtual sink (`chrome_audio`)
2. PulseAudio creates monitor source (`chrome_audio.monitor`)
3. FFmpeg captures from monitor source
4. FFmpeg muxes audio with video for RTMP output

## PulseAudio Configuration

### User Mode Setup (Recommended)

User mode is more reliable than system mode for containerized environments:

```bash
# Setup XDG runtime directory
export XDG_RUNTIME_DIR=/tmp/pulse-runtime
mkdir -p "$XDG_RUNTIME_DIR"
chmod 700 "$XDG_RUNTIME_DIR"

# Create PulseAudio config directory
mkdir -p /root/.config/pulse

# Create minimal config with virtual sink
cat > /root/.config/pulse/default.pa << 'EOF'
.fail
load-module module-null-sink sink_name=chrome_audio sink_properties=device.description="ChromeAudio"
set-default-sink chrome_audio
load-module module-native-protocol-unix auth-anonymous=1
EOF

# Start PulseAudio in user mode
pulseaudio --start --exit-idle-time=-1 --daemonize=yes

# Export socket path for child processes
export PULSE_SERVER=unix:$XDG_RUNTIME_DIR/pulse/native
```

### Verify PulseAudio

```bash
# Check PulseAudio is running
pulseaudio --check && echo "PulseAudio is running"

# List sinks
pactl list short sinks

# Expected output:
# 0  chrome_audio  module-null-sink.c  s16le 2ch 44100Hz  RUNNING

# Verify monitor source exists
pactl list short sources | grep chrome_audio.monitor
```

### Manual Sink Creation

If the sink doesn't auto-create from config:

```bash
# Create virtual sink manually
pactl load-module module-null-sink sink_name=chrome_audio sink_properties=device.description="ChromeAudio"

# Set as default sink
pactl set-default-sink chrome_audio

# Verify
pactl list short sinks | grep chrome_audio
```

## FFmpeg Audio Capture

### Input Configuration

```bash
# Capture from PulseAudio monitor
-f pulse -i chrome_audio.monitor

# Audio buffering (prevents buffer underruns)
-thread_queue_size 1024

# Real-time timing
-use_wallclock_as_timestamps 1

# Audio drift recovery (resync when drift exceeds 22ms)
-filter:a aresample=async=1000:first_pts=0
```

### Audio/Video Sync

```bash
# Video buffering (increased for a/v sync)
-thread_queue_size 1024  # Increased from 512

# Remove -shortest flag (was causing audio dropouts)
# -shortest  # REMOVED - caused audio dropouts during video buffering
```

### Graceful Fallback

If PulseAudio is unavailable, FFmpeg falls back to silent audio:

```bash
# Check if PulseAudio is available
if pactl info &>/dev/null && pactl list sinks | grep -q chrome_audio; then
  AUDIO_INPUT="-f pulse -i chrome_audio.monitor"
else
  AUDIO_INPUT="-f lavfi -i anullsrc"  # Silent audio fallback
fi
```

## Troubleshooting

### PulseAudio Not Starting

**Check if PulseAudio is running:**
```bash
pulseaudio --check
echo $?  # Should be 0 if running
```

**If not running:**
```bash
# Kill any existing instances
pulseaudio --kill
pkill -9 pulseaudio
sleep 2

# Start fresh
pulseaudio --start --exit-idle-time=-1 --daemonize=yes
```

**Check logs:**
```bash
# PulseAudio logs
journalctl -u pulseaudio --no-pager -n 50

# Or check syslog
tail -50 /var/log/syslog | grep pulse
```

### Virtual Sink Not Created

**Verify sink exists:**
```bash
pactl list short sinks | grep chrome_audio
```

**If missing, create manually:**
```bash
pactl load-module module-null-sink sink_name=chrome_audio sink_properties=device.description="ChromeAudio"
```

**Check module is loaded:**
```bash
pactl list short modules | grep null-sink
```

### Permission Denied Errors

**Symptom:** FFmpeg fails with "Permission denied" when accessing PulseAudio

**Cause:** Insufficient permissions for PulseAudio socket

**Solution:**
```bash
# Add user to pulse-access group
usermod -aG pulse-access root

# Create /run/pulse with proper permissions
mkdir -p /run/pulse
chmod 777 /run/pulse

# Restart PulseAudio
pulseaudio --kill
pulseaudio --start --exit-idle-time=-1 --daemonize=yes
```

### No Audio in Stream

**Check FFmpeg is capturing audio:**
```bash
# Test audio capture
ffmpeg -f pulse -i chrome_audio.monitor -t 5 test.wav

# Play test file
ffplay test.wav
```

**Check Chrome is outputting to PulseAudio:**
```bash
# Monitor PulseAudio activity
pactl subscribe

# Should see events when Chrome plays audio:
# Event 'change' on sink #0
```

**Verify PULSE_SERVER environment:**
```bash
echo $PULSE_SERVER
# Should be: unix:/tmp/pulse-runtime/pulse/native

# Test connection
pactl -s "$PULSE_SERVER" info
```

### Audio Drift or Desync

**Symptom:** Audio gradually drifts out of sync with video

**Cause:** Timing issues between audio and video capture

**Solution:** Use async resampling filter (already configured):

```bash
# Audio drift recovery filter
-filter:a aresample=async=1000:first_pts=0

# Resyncs audio when drift exceeds 22ms
# first_pts=0 ensures proper timestamp alignment
```

**Additional fixes:**
```bash
# Use wall clock timestamps for accurate timing
-use_wallclock_as_timestamps 1

# Increase buffer sizes for both audio and video
-thread_queue_size 1024  # Both audio and video inputs
```

### Audio Dropouts

**Symptom:** Intermittent audio dropouts or stuttering

**Cause:** Buffer underruns or `-shortest` flag

**Solution:** Update to latest code (commit b9d2e41 fixed this):

**Three key changes:**
1. **Adequate buffering** for both audio and video inputs
   - Audio: `thread_queue_size=1024` prevents buffer underruns
   - Video: `thread_queue_size=1024` for better a/v sync

2. **Wall clock timestamps** for accurate audio timing
   - `use_wallclock_as_timestamps=1` maintains real-time timing

3. **Removed `-shortest` flag**
   - Was causing audio dropouts during video buffering
   - Now both streams run independently

**FFmpeg Args:**
```bash
# Audio input with buffering
-f pulse -i chrome_audio.monitor \
-thread_queue_size 1024 \
-use_wallclock_as_timestamps 1 \
-filter:a aresample=async=1000:first_pts=0

# Video input with buffering
-thread_queue_size 1024

# NO -shortest flag (removed)
```

## Deployment

### Vast.ai Automatic Setup

The `deploy-vast.sh` script automatically configures PulseAudio:

```bash
# Install PulseAudio
apt-get install -y pulseaudio pulseaudio-utils

# Setup user mode
export XDG_RUNTIME_DIR=/tmp/pulse-runtime
mkdir -p "$XDG_RUNTIME_DIR"
chmod 700 "$XDG_RUNTIME_DIR"

# Create config
mkdir -p /root/.config/pulse
cat > /root/.config/pulse/default.pa << 'EOF'
.fail
load-module module-null-sink sink_name=chrome_audio sink_properties=device.description="ChromeAudio"
set-default-sink chrome_audio
load-module module-native-protocol-unix auth-anonymous=1
EOF

# Start PulseAudio
pulseaudio --start --exit-idle-time=-1 --daemonize=yes

# Verify and create sink if needed
if ! pactl list short sinks | grep -q chrome_audio; then
  pactl load-module module-null-sink sink_name=chrome_audio
  pactl set-default-sink chrome_audio
fi

# Export for PM2
export PULSE_SERVER=unix:$XDG_RUNTIME_DIR/pulse/native
```

### PM2 Configuration

The `ecosystem.config.cjs` passes PulseAudio environment to child processes:

```javascript
env: {
  PULSE_SERVER: 'unix:/tmp/pulse-runtime/pulse/native',
  XDG_RUNTIME_DIR: '/tmp/pulse-runtime',
  STREAM_AUDIO_ENABLED: 'true',
  PULSE_AUDIO_DEVICE: 'chrome_audio.monitor',
}
```

## Performance

### CPU Usage

PulseAudio adds minimal CPU overhead:
- Virtual sink: <1% CPU
- Monitor source: <1% CPU
- FFmpeg audio encoding: ~2-3% CPU (AAC)

### Latency

Audio latency is typically <50ms:
- Chrome → PulseAudio: ~10ms
- PulseAudio → FFmpeg: ~20ms
- FFmpeg encoding: ~10ms
- Total: ~40ms

### Memory Usage

PulseAudio memory footprint:
- Daemon: ~10-15MB
- Virtual sink buffer: ~2-5MB
- Total: ~15-20MB

## Advanced Configuration

### Custom Sink Properties

```bash
# Create sink with custom properties
pactl load-module module-null-sink \
  sink_name=chrome_audio \
  sink_properties=device.description="ChromeAudio" \
  rate=48000 \
  channels=2 \
  format=s16le
```

### Multiple Sinks

```bash
# Create multiple sinks for different audio sources
pactl load-module module-null-sink sink_name=game_music
pactl load-module module-null-sink sink_name=game_sfx

# Route Chrome to specific sink
export PULSE_SINK=game_music
```

### Audio Filters

```bash
# Apply audio filters in FFmpeg
-filter:a "volume=1.5,highpass=f=100,lowpass=f=15000"

# Normalize audio levels
-filter:a "loudnorm=I=-16:TP=-1.5:LRA=11"
```
