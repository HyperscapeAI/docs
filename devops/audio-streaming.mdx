## Overview

Hyperscape captures game audio (music and sound effects) for RTMP streams using PulseAudio virtual sinks. This feature was added in February 2026 to enhance stream quality.

## Architecture

```mermaid
flowchart LR
    A[Chrome Browser] --> B[PulseAudio Virtual Sink]
    B --> C[Monitor Device]
    C --> D[FFmpeg]
    D --> E[RTMP Streams]
```

**Components:**
1. **Chrome Browser** - Plays game audio
2. **PulseAudio Virtual Sink** (`chrome_audio`) - Captures audio output
3. **Monitor Device** (`chrome_audio.monitor`) - Provides audio input to FFmpeg
4. **FFmpeg** - Encodes and streams to RTMP destinations

## PulseAudio Setup

### User Mode Configuration

PulseAudio runs in user mode (more reliable than system mode):

```bash
# Setup XDG runtime directory
export XDG_RUNTIME_DIR=/tmp/pulse-runtime
mkdir -p "$XDG_RUNTIME_DIR"
chmod 700 "$XDG_RUNTIME_DIR"

# Create PulseAudio config directory
mkdir -p /root/.config/pulse
```

### Virtual Sink Configuration

Create `~/.config/pulse/default.pa`:

```bash
cat > /root/.config/pulse/default.pa << 'PULSEEOF'
.fail
load-module module-null-sink sink_name=chrome_audio sink_properties=device.description="ChromeAudio"
set-default-sink chrome_audio
load-module module-native-protocol-unix auth-anonymous=1
PULSEEOF
```

**Configuration Breakdown:**
- `.fail` - Exit on module load failure
- `module-null-sink` - Virtual audio sink (no physical output)
- `sink_name=chrome_audio` - Named sink for FFmpeg capture
- `set-default-sink` - Chrome uses this sink by default
- `module-native-protocol-unix` - Unix socket for FFmpeg access

### Start PulseAudio

```bash
# Start in user mode
pulseaudio --start --exit-idle-time=-1 --daemonize=yes

# Verify it's running
pulseaudio --check && echo "Running" || echo "Not running"

# List sinks
pactl list short sinks
```

**Expected Output:**
```
0	chrome_audio	PipeWire	s16le 2ch 48000Hz	RUNNING
```

### Verify Virtual Sink

```bash
# Check if chrome_audio sink exists
pactl list short sinks | grep chrome_audio

# If missing, create manually
pactl load-module module-null-sink sink_name=chrome_audio sink_properties=device.description="ChromeAudio"
pactl set-default-sink chrome_audio
```

## FFmpeg Audio Capture

### Audio Input Configuration

```bash
# Capture from PulseAudio monitor
-f pulse -i chrome_audio.monitor

# Audio buffering (prevents buffer underruns)
-thread_queue_size 1024

# Wall clock timestamps (maintains real-time timing)
-use_wallclock_as_timestamps 1

# Async resampling (recovers from audio drift > 22ms)
-filter:a aresample=async=1000:first_pts=0
```

### Audio Encoding

```bash
# AAC encoding
-c:a aac -b:a 128k -ar 44100
```

### Complete FFmpeg Command

```bash
ffmpeg \
  -f pulse -i chrome_audio.monitor \
  -thread_queue_size 1024 \
  -use_wallclock_as_timestamps 1 \
  -filter:a aresample=async=1000:first_pts=0 \
  -f x11grab -i :99 \
  -thread_queue_size 1024 \
  -c:v libx264 -preset ultrafast -tune film \
  -b:v 4500k -bufsize 18000k \
  -c:a aac -b:a 128k -ar 44100 \
  -f flv rtmp://live.twitch.tv/app/your-stream-key
```

## Audio Stability Improvements

### Buffer Underrun Prevention

**Problem:** Intermittent audio dropouts during streams.

**Solution:** Three key improvements (commit b9d2e41):

**1. Buffer Both Audio and Video Inputs:**
```bash
# Audio buffering
-f pulse -i chrome_audio.monitor -thread_queue_size 1024

# Video buffering (increased from 512)
-f x11grab -i :99 -thread_queue_size 1024
```

**2. Wall Clock Timestamps:**
```bash
# Use wall clock for accurate audio timing
-use_wallclock_as_timestamps 1
```

**3. Async Resampling:**
```bash
# Recover from audio drift exceeding 22ms
-filter:a aresample=async=1000:first_pts=0
```

**4. Remove -shortest Flag:**
```bash
# ❌ Old: Caused audio dropouts during video buffering
-shortest

# ✅ New: Removed
# (no -shortest flag)
```

### Audio/Video Sync

**Video Thread Queue:**
```bash
# Increased from 512 to 1024 for better a/v sync
-thread_queue_size 1024
```

**Benefits:**
- Prevents audio buffer underruns
- Maintains real-time audio timing
- Recovers from audio drift automatically
- Better audio/video synchronization

## Permissions Configuration

### PulseAudio Access

```bash
# Add root user to pulse-access group
usermod -aG pulse-access root

# Create /run/pulse with proper permissions
mkdir -p /run/pulse
chmod 777 /run/pulse
```

### Environment Variables

Export in both deploy script and PM2 config:

```bash
# Deploy script
export PULSE_SERVER="unix:/tmp/pulse-runtime/pulse/native"
export XDG_RUNTIME_DIR="/tmp/pulse-runtime"

# PM2 config (ecosystem.config.cjs)
env: {
  PULSE_SERVER: "unix:/tmp/pulse-runtime/pulse/native",
  XDG_RUNTIME_DIR: "/tmp/pulse-runtime",
  STREAM_AUDIO_ENABLED: "true",
  PULSE_AUDIO_DEVICE: "chrome_audio.monitor"
}
```

## Graceful Fallback

If PulseAudio is not available, FFmpeg falls back to silent audio:

```bash
# Check if PulseAudio is running and sink exists
if pactl info &>/dev/null && pactl list sinks | grep -q chrome_audio; then
  AUDIO_INPUT="-f pulse -i chrome_audio.monitor"
  echo "[stream] Using PulseAudio audio capture"
else
  AUDIO_INPUT="-f lavfi -i anullsrc"
  echo "[stream] PulseAudio not available, using silent audio"
fi
```

**Fallback Conditions:**
- PulseAudio not running
- `chrome_audio` sink doesn't exist
- Permissions issues
- PulseAudio daemon crashed

## Configuration

### Environment Variables

```bash
# Enable audio capture (default: true)
STREAM_AUDIO_ENABLED=true

# PulseAudio device (monitor of virtual sink)
PULSE_AUDIO_DEVICE=chrome_audio.monitor

# PulseAudio server socket
PULSE_SERVER=unix:/tmp/pulse-runtime/pulse/native

# Runtime directory for PulseAudio
XDG_RUNTIME_DIR=/tmp/pulse-runtime
```

### Disable Audio Capture

To stream without audio:

```bash
STREAM_AUDIO_ENABLED=false
```

FFmpeg will use silent audio (`anullsrc`).

## Troubleshooting

### Check PulseAudio Status

```bash
# Check if PulseAudio is running
pulseaudio --check && echo "Running" || echo "Not running"

# Get PulseAudio info
pactl info

# List all sinks
pactl list short sinks

# List all sources (monitors)
pactl list short sources
```

### Verify chrome_audio Sink

```bash
# Check if sink exists
pactl list sinks | grep chrome_audio

# Expected output:
# Name: chrome_audio
# Description: ChromeAudio
# State: RUNNING
```

### Test Audio Capture

```bash
# Record 5 seconds of audio
ffmpeg -f pulse -i chrome_audio.monitor -t 5 test.wav

# Play back
ffplay test.wav
```

### Restart PulseAudio

```bash
# Kill PulseAudio
pulseaudio --kill
pkill -9 pulseaudio

# Wait for cleanup
sleep 2

# Restart
pulseaudio --start --exit-idle-time=-1 --daemonize=yes

# Recreate sink if needed
pactl load-module module-null-sink sink_name=chrome_audio
pactl set-default-sink chrome_audio
```

### Check FFmpeg Audio Input

```bash
# List PulseAudio sources
ffmpeg -f pulse -list_devices true -i dummy

# Expected output should include:
# [pulse @ 0x...] source #0: chrome_audio.monitor
```

### Permission Issues

```bash
# Check user groups
groups root

# Should include: pulse-access

# Add if missing
usermod -aG pulse-access root

# Check /run/pulse permissions
ls -la /run/pulse

# Should be: drwxrwxrwx
```

### Audio Drift Issues

If audio drifts out of sync with video:

```bash
# Increase async resampling threshold
-filter:a aresample=async=2000:first_pts=0  # 2000ms instead of 1000ms

# Or disable async resampling (not recommended)
# -filter:a aresample=first_pts=0
```

### No Audio in Stream

**1. Check PulseAudio is running:**
```bash
pactl info
```

**2. Check Chrome is using chrome_audio sink:**
```bash
pactl list sink-inputs
```

**3. Check FFmpeg is capturing:**
```bash
ps aux | grep ffmpeg | grep pulse
```

**4. Check stream key is set:**
```bash
echo $TWITCH_STREAM_KEY
```

**5. Check PM2 environment:**
```bash
bunx pm2 show hyperscape-duel | grep PULSE
```

## Advanced Configuration

### Custom Sink Name

```bash
# Use different sink name
PULSE_AUDIO_DEVICE=my_custom_sink.monitor

# Create custom sink
pactl load-module module-null-sink sink_name=my_custom_sink
```

### Multiple Audio Sources

Capture from multiple sources:

```bash
# Mix game audio + microphone
-f pulse -i chrome_audio.monitor \
-f pulse -i alsa_input.usb-0000:00:14.0-1 \
-filter_complex "[0:a][1:a]amix=inputs=2[aout]" \
-map "[aout]"
```

### Audio Quality Settings

```bash
# Higher quality audio
-c:a aac -b:a 256k -ar 48000

# Lower quality (saves bandwidth)
-c:a aac -b:a 64k -ar 22050
```

## Deployment Integration

### Vast.ai Deploy Script

The `scripts/deploy-vast.sh` automatically configures PulseAudio:

```bash
# Setup PulseAudio for audio capture
echo "[deploy] Setting up PulseAudio for audio streaming..."

# Kill any existing PulseAudio
pulseaudio --kill 2>/dev/null || true
pkill -9 pulseaudio 2>/dev/null || true
sleep 2

# Setup XDG runtime directory
export XDG_RUNTIME_DIR=/tmp/pulse-runtime
mkdir -p "$XDG_RUNTIME_DIR"
chmod 700 "$XDG_RUNTIME_DIR"

# Create config
mkdir -p /root/.config/pulse
cat > /root/.config/pulse/default.pa << 'PULSEEOF'
.fail
load-module module-null-sink sink_name=chrome_audio sink_properties=device.description="ChromeAudio"
set-default-sink chrome_audio
load-module module-native-protocol-unix auth-anonymous=1
PULSEEOF

# Start PulseAudio
pulseaudio --start --exit-idle-time=-1 --daemonize=yes
sleep 3

# Verify and create sink if needed
if pulseaudio --check; then
  echo "[deploy] PulseAudio is running"
  if ! pactl list short sinks | grep -q chrome_audio; then
    pactl load-module module-null-sink sink_name=chrome_audio
    pactl set-default-sink chrome_audio
  fi
fi

# Export for child processes
export PULSE_SERVER="unix:$XDG_RUNTIME_DIR/pulse/native"
```
