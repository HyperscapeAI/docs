## Overview

Hyperscape's streaming system captures game music and sound effects via PulseAudio virtual sink. Chrome outputs audio to a virtual sink, and FFmpeg captures from the sink's monitor device.

## Architecture

```
Chrome (game audio) → PulseAudio (chrome_audio sink) → FFmpeg (monitor capture) → RTMP streams
```

**Key Components:**
- **Virtual Sink**: `chrome_audio` - PulseAudio null sink for Chrome audio output
- **Monitor Device**: `chrome_audio.monitor` - FFmpeg captures from this
- **User Mode**: PulseAudio runs in user mode (more reliable than system mode)

## Automatic Setup

The `scripts/deploy-vast.sh` script automatically configures PulseAudio:

```bash
# 1. Kill existing PulseAudio
pulseaudio --kill
pkill -9 pulseaudio

# 2. Setup XDG runtime directory
export XDG_RUNTIME_DIR=/tmp/pulse-runtime
mkdir -p "$XDG_RUNTIME_DIR"
chmod 700 "$XDG_RUNTIME_DIR"

# 3. Create PulseAudio config
cat > /root/.config/pulse/default.pa << 'EOF'
.fail
load-module module-null-sink sink_name=chrome_audio sink_properties=device.description="ChromeAudio"
set-default-sink chrome_audio
load-module module-native-protocol-unix auth-anonymous=1
EOF

# 4. Start PulseAudio in user mode
pulseaudio --start --exit-idle-time=-1 --daemonize=yes

# 5. Verify sink exists
pactl list short sinks | grep chrome_audio

# 6. Export PULSE_SERVER for child processes
export PULSE_SERVER="unix:$XDG_RUNTIME_DIR/pulse/native"
```

## Manual Setup

### Install PulseAudio

```bash
apt-get update
apt-get install -y pulseaudio pulseaudio-utils
```

### Create Virtual Sink

```bash
# Load null sink module
pactl load-module module-null-sink \
  sink_name=chrome_audio \
  sink_properties=device.description="ChromeAudio"

# Set as default sink
pactl set-default-sink chrome_audio

# Verify
pactl list short sinks
```

### Configure Chrome

Chrome automatically uses the default PulseAudio sink. No additional configuration needed.

### Configure FFmpeg

FFmpeg captures from the monitor device:

```bash
# Audio input
-f pulse -i chrome_audio.monitor

# Audio buffering (prevents underruns)
-thread_queue_size 1024

# Real-time timing
-use_wallclock_as_timestamps 1

# Async resampling (recovers from drift)
-filter:a aresample=async=1000:first_pts=0
```

## Audio Stability Improvements

Recent commits improved audio stability to prevent dropouts and desync (commit b9d2e41, Feb 26 2026):

### Buffering

**Problem:** Buffer underruns caused intermittent audio dropouts.

**Solution:** Adequate buffering for both audio and video inputs:

```bash
# Audio input buffering
-thread_queue_size 1024

# Video input buffering (increased for a/v sync)
-thread_queue_size 1024  # Increased from 512
```

### Wall Clock Timestamps

**Problem:** Audio timing drift caused gradual desync.

**Solution:** Use wall clock timestamps for accurate real-time timing:

```bash
-use_wallclock_as_timestamps 1
```

### Async Resampling

**Problem:** Audio drift exceeding 22ms caused permanent desync.

**Solution:** Async resampling filter recovers from drift:

```bash
# Resample if drift exceeds 1000 samples (22ms at 44.1kHz)
-filter:a aresample=async=1000:first_pts=0
```

### Removed -shortest Flag

**Problem:** `-shortest` flag caused audio dropouts during video buffering.

**Solution:** Removed `-shortest` flag from FFmpeg args.

## Graceful Fallback

If PulseAudio is not available, FFmpeg falls back to silent audio:

```bash
# Check if PulseAudio is accessible
if pactl info &>/dev/null && pactl list sinks | grep -q chrome_audio; then
    echo "Using PulseAudio for audio capture"
    AUDIO_INPUT="-f pulse -i chrome_audio.monitor"
else
    echo "PulseAudio not available, using silent audio"
    AUDIO_INPUT="-f lavfi -i anullsrc"
fi
```

**Why Silent Audio:**
- Many RTMP servers require an audio track
- Silent audio prevents stream rejection
- Better than stream failure

## Permissions

### User Mode vs System Mode

**User Mode (Recommended):**
- More reliable
- Easier to configure
- No system-wide daemon conflicts

**System Mode (Not Recommended):**
- Requires root permissions
- Can conflict with existing PulseAudio instances
- More complex permission management

### Permission Fixes

If you get permission errors:

```bash
# Add root to pulse-access group
usermod -aG pulse-access root

# Create /run/pulse with proper permissions
mkdir -p /run/pulse
chmod 777 /run/pulse

# Export PULSE_SERVER
export PULSE_SERVER=unix:/tmp/pulse-runtime/pulse/native
```

## Troubleshooting

### Verify PulseAudio

```bash
# Check PulseAudio is running
pulseaudio --check && echo "PulseAudio is running"

# List sinks
pactl list short sinks

# Should see chrome_audio
pactl list short sinks | grep chrome_audio

# Check default sink
pactl info | grep "Default Sink"
```

### Test Audio Capture

```bash
# Capture 5 seconds of audio
ffmpeg -f pulse -i chrome_audio.monitor -t 5 test.wav

# Play back
ffplay test.wav

# Should hear game audio if Chrome is playing
```

### Monitor PulseAudio Activity

```bash
# Subscribe to PulseAudio events
pactl subscribe

# Should see events when Chrome plays audio:
# Event 'change' on sink #0
# Event 'new' on sink-input #1
```

### Check Chrome Audio Output

```bash
# List sink inputs (active audio streams)
pactl list short sink-inputs

# Should see Chrome when game is playing audio
```

### Common Issues

**No audio in stream:**
- Verify PulseAudio is running: `pulseaudio --check`
- Check chrome_audio sink exists: `pactl list short sinks | grep chrome_audio`
- Verify environment variables: `echo $PULSE_SERVER`
- Test audio capture: `ffmpeg -f pulse -i chrome_audio.monitor -t 5 test.wav`

**Permission denied:**
- Add root to pulse-access group: `usermod -aG pulse-access root`
- Create /run/pulse: `mkdir -p /run/pulse && chmod 777 /run/pulse`
- Export PULSE_SERVER: `export PULSE_SERVER=unix:/tmp/pulse-runtime/pulse/native`

**Audio dropouts:**
- Increase thread_queue_size: `-thread_queue_size 1024`
- Enable wall clock timestamps: `-use_wallclock_as_timestamps 1`
- Add async resampling: `-filter:a aresample=async=1000:first_pts=0`

**Audio desync:**
- Check for drift in FFmpeg logs
- Verify async resampling is enabled
- Increase video buffering: `-thread_queue_size 1024`

## FFmpeg Audio Configuration

### Complete FFmpeg Args

```bash
# Audio input from PulseAudio
-thread_queue_size 1024 \
-use_wallclock_as_timestamps 1 \
-f pulse \
-ac 2 \
-ar 44100 \
-i chrome_audio.monitor \

# Audio filter (async resample)
-filter:a aresample=async=1000:first_pts=0 \

# Audio codec
-c:a aac \
-b:a 128k \
-ar 44100 \
-flags +global_header
```

### Audio Codec Settings

```bash
# AAC codec (best compatibility)
-c:a aac

# Bitrate (128k recommended for music)
-b:a 128k

# Sample rate (44.1kHz standard)
-ar 44100

# Global header (required for RTMP)
-flags +global_header
```
