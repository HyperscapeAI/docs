## Overview

Hyperscape uses Docker for:

- **Asset CDN**: nginx serving game assets
- **PostgreSQL**: Database for player data
- **Development services**: Local infrastructure
- **Production deployment**: Multi-stage Docker builds for Railway/cloud hosting

## Prerequisites

- [Docker Desktop](https://docker.com/products/docker-desktop) (macOS/Windows)
- Or Docker Engine on Linux: `apt install docker.io`

## CDN Container

### Start CDN

```bash
bun run cdn:up
```

This starts an nginx container serving assets from `packages/server/world/assets/` on port 8080.

### Stop CDN

```bash
bun run cdn:down
```

### Automatic Start

The CDN starts automatically with `bun run dev`. Only run manually if using services separately.

## PostgreSQL Container

PostgreSQL starts automatically when the server runs via Docker Compose.

### Configuration

Default connection:

```
Host: localhost
Port: 5432
Database: hyperscape
User: postgres
Password: postgres
```

### Manual Control

```bash
cd packages/server
docker-compose up postgres    # Start PostgreSQL
docker-compose down postgres  # Stop PostgreSQL
```

## Docker Compose

The server package includes `docker-compose.yml`:

```yaml
services:
  postgres:
    image: postgres:15
    ports:
      - "5432:5432"
    environment:
      POSTGRES_DB: hyperscape
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
    volumes:
      - postgres-data:/var/lib/postgresql/data

  cdn:
    image: nginx:alpine
    ports:
      - "8080:80"
    volumes:
      - ./world/assets:/usr/share/nginx/html:ro
```

## Resetting Containers

### Reset Database

<Warning>
  This deletes all local data (characters, inventory, progress).
</Warning>

```bash
# Stop containers
docker stop hyperscape-postgres
docker rm hyperscape-postgres

# Remove volumes
docker volume rm hyperscape-postgres-data
docker volume rm server_postgres-data

# Verify
docker volume ls | grep hyperscape

# Restart
bun run dev
```

### Reset CDN

```bash
docker stop hyperscape-cdn
docker rm hyperscape-cdn
bun run cdn:up
```

## No Docker Alternative

If you can't run Docker locally:

### External PostgreSQL

Use a hosted database (e.g., [Neon](https://neon.tech)):

```bash
# packages/server/.env
DATABASE_URL=postgresql://user:pass@host.neon.tech:5432/db
```

### External CDN

Host assets on cloud storage:

```bash
# packages/server/.env and packages/client/.env
PUBLIC_CDN_URL=https://your-cdn.example.com
```

## Production Docker Build

The repository includes a multi-stage Dockerfile for production deployment.

### Dockerfile.server

**File**: `Dockerfile.server`

**Features**:
- **Multi-stage build**: Separate builder and runtime stages for smaller images
- **Native module support**: Includes build dependencies for canvas, better-sqlite3
- **Asset cloning**: Automatically clones game manifests from assets repository
- **Build order**: Builds physx-js-webidl → shared → server in correct dependency order
- **Health check**: Built-in health monitoring on `/status` endpoint
- **Optimized runtime**: Minimal production image with only runtime dependencies

**Build from repository root**:

```bash
docker build -f Dockerfile.server -t hyperscape-server .
```

**Run**:

```bash
docker run -p 5555:5555 \
  -e DATABASE_URL=postgresql://... \
  -e JWT_SECRET=your-secret \
  -e PRIVY_APP_ID=your-app-id \
  -e PRIVY_APP_SECRET=your-secret \
  hyperscape-server
```

### CI Environment Detection

The `ensure-assets.mjs` script automatically detects CI/production environments and skips asset download:

```javascript
function isCI() {
  return !!(
    process.env.CI ||
    process.env.RAILWAY_ENVIRONMENT ||
    process.env.RAILWAY_SERVICE_ID ||
    process.env.VERCEL ||
    process.env.NETLIFY ||
    process.env.GITHUB_ACTIONS ||
    process.env.SKIP_ASSETS
  );
}
```

**Why**: Assets are served from CDN in production, not bundled with the server. This keeps Docker images small and builds fast.

### Railway-Specific Configuration

When deploying to Railway, assets are cloned during the build phase:

```toml
# nixpacks.toml
[phases.assets]
dependsOn = ["install"]
cmds = ["git clone --depth 1 https://github.com/HyperscapeAI/assets.git packages/server/world/assets"]
```

The `.railwayignore` file excludes large directories from upload:

```
node_modules/
.git/
packages/server/world/assets/  # Cloned during build
packages/client/public/assets/
```

<Info>
Railway builds clone the assets repository during the build phase, so they don't need to be uploaded from your local machine.
</Info>
