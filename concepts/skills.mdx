## Overview

Hyperscape features a RuneScape-inspired skill system with leveling, XP gain, and level requirements for equipment and activities.

## Available Skills

Hyperscape has **11 skills** total:

### Combat Skills

| Skill | Purpose |
|-------|---------|
| **Attack** | Melee accuracy, weapon requirements |
| **Strength** | Melee damage |
| **Defense** | Damage reduction, armor requirements |
| **Constitution** | Health points |
| **Prayer** | Protection prayers and combat buffs |

### Gathering Skills

| Skill | Activity |
|-------|----------|
| **Woodcutting** | Chop trees for logs |
| **Mining** | Mine rocks for ores |
| **Fishing** | Catch fish at water spots |

### Artisan Skills

| Skill | Activity |
|-------|----------|
| **Firemaking** | Create fires from logs |
| **Cooking** | Prepare food from raw fish |
| **Smithing** | Smelt ores into bars and smith equipment |

## XP and Leveling

### XP Formula

Hyperscape uses RuneScape's XP curve:

```
XP for Level N = floor(sum(floor(L + 300 * 2^(L/7))) / 4) for L = 1 to N-1
```

### Level Milestones

| Level | Total XP |
|-------|----------|
| 10 | 1,154 |
| 20 | 4,470 |
| 30 | 13,363 |
| 50 | 101,333 |
| 70 | 737,627 |
| 99 | 13,034,431 |

## Resource Gathering

### Woodcutting

Requirements:
- Hatchet in inventory
- Click tree to chop

Success rate improves with level. Higher-level trees require higher Woodcutting levels.

| Tree | Level | XP |
|------|-------|-----|
| Normal | 1 | 25 |
| Oak | 15 | 37 |
| Willow | 30 | 68 |

### Fishing

Requirements:
- Fishing rod in inventory
- Click fishing spot

| Fish | Level | XP |
|------|-------|-----|
| Shrimp | 1 | 10 |
| Trout | 20 | 50 |
| Lobster | 40 | 90 |

## Artisan Skills

### Firemaking

Use tinderbox on logs in inventory to create a fire.

| Log | Level | XP |
|-----|-------|-----|
| Normal | 1 | 40 |
| Oak | 15 | 60 |
| Willow | 30 | 90 |

### Cooking

Use raw fish on a fire to cook.

| Food | Level | XP | Heals |
|------|-------|-----|-------|
| Shrimp | 1 | 30 | 3 HP |
| Trout | 15 | 70 | 7 HP |
| Lobster | 40 | 120 | 12 HP |

<Warning>
  Cooking can fail at low levels, burning the food.
</Warning>

### Smithing

Smelt ores into bars at furnaces, then smith bars into equipment at anvils.

#### Smelting (at Furnace)

| Bar | Level | Ores Required | XP | Success Rate |
|-----|-------|---------------|-----|--------------|
| Bronze | 1 | 1 Copper + 1 Tin | 6.25 | 100% |
| Iron | 15 | 1 Iron Ore | 12.5 | 50% |
| Steel | 30 | 1 Iron Ore + 2 Coal | 17.5 | 100% |
| Mithril | 50 | 1 Mithril Ore + 4 Coal | 30 | 100% |
| Adamant | 70 | 1 Adamantite Ore + 6 Coal | 37.5 | 100% |
| Rune | 85 | 1 Runite Ore + 8 Coal | 50 | 100% |

<Info>
  Iron ore has a 50% failure rate when smelting, matching OSRS mechanics.
</Info>

#### Smithing (at Anvil)

Requires a hammer in inventory. Examples:

| Item | Level | Bars Required | XP |
|------|-------|---------------|-----|
| Bronze Sword | 1 | 1 Bronze | 12.5 |
| Iron Platebody | 33 | 5 Iron | 125 |
| Steel Platelegs | 36 | 3 Steel | 75 |
| Mithril Scimitar | 55 | 2 Mithril | 100 |

<Warning>
  You must have a hammer in your inventory to smith items at an anvil.
</Warning>

| File | Purpose |
|------|---------|

## Default Skill Values

Skills start at level 1 with 0 XP, except Constitution which starts at level 10:

```typescript
// From packages/shared/src/entities/player/PlayerEntity.ts
playerData.skills = {
  attack: { level: 1, xp: 0 },
  strength: { level: 1, xp: 0 },
  defense: { level: 1, xp: 0 },
  constitution: { level: 10, xp: 1154 },  // Starts at level 10
  prayer: { level: 1, xp: 0 },
  woodcutting: { level: 1, xp: 0 },
  mining: { level: 1, xp: 0 },
  fishing: { level: 1, xp: 0 },
  firemaking: { level: 1, xp: 0 },
  cooking: { level: 1, xp: 0 },
  smithing: { level: 1, xp: 0 },
};
```

<Info>
  Constitution starts at level 10 (1,154 XP) like RuneScape's Hitpoints.
  Player health equals their Constitution level.
</Info>
