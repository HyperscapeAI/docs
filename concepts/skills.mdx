## Overview

Hyperscape features a RuneScape-inspired skill system with leveling, XP gain, and level requirements for equipment and activities.

## Available Skills

Hyperscape has **11 skills** total:

### Combat Skills

| Skill | Purpose |
|-------|---------|
| **Attack** | Melee accuracy, weapon requirements |
| **Strength** | Melee damage |
| **Defense** | Damage reduction, armor requirements |
| **Constitution** | Health points |
| **Ranged** | Ranged combat accuracy and damage |

### Gathering Skills

| Skill | Activity |
|-------|----------|
| **Woodcutting** | Chop trees for logs |
| **Fishing** | Catch fish at water spots |
| **Mining** | Mine ore from rocks |

### Processing Skills

| Skill | Activity |
|-------|----------|
| **Firemaking** | Create fires from logs |
| **Cooking** | Prepare food from raw fish |
| **Smithing** | Smelt ores into bars and smith equipment |

## XP and Leveling

### XP Formula

Hyperscape uses RuneScape's XP curve:

```
XP for Level N = floor(sum(floor(L + 300 * 2^(L/7))) / 4) for L = 1 to N-1
```

### Level Milestones

| Level | Total XP |
|-------|----------|
| 10 | 1,154 |
| 20 | 4,470 |
| 30 | 13,363 |
| 50 | 101,333 |
| 70 | 737,627 |
| 99 | 13,034,431 |

## Resource Gathering

### Woodcutting

Requirements:
- Hatchet in inventory
- Click tree to chop

Success rate improves with level. Higher-level trees require higher Woodcutting levels.

| Tree | Level | XP |
|------|-------|-----|
| Normal | 1 | 25 |
| Oak | 15 | 37 |
| Willow | 30 | 68 |

### Fishing

Requirements:
- Fishing rod in inventory
- Click fishing spot

| Fish | Level | XP |
|------|-------|-----|
| Shrimp | 1 | 10 |
| Trout | 20 | 50 |
| Lobster | 40 | 90 |

## Processing Skills

### Firemaking

Use tinderbox on logs in inventory to create a fire.

| Log | Level | XP |
|-----|-------|-----|
| Normal | 1 | 40 |
| Oak | 15 | 60 |
| Willow | 30 | 90 |

### Cooking

Use raw fish on a fire to cook.

| Food | Level | XP | Heals |
|------|-------|-----|-------|
| Shrimp | 1 | 30 | 3 HP |
| Trout | 15 | 70 | 7 HP |
| Lobster | 40 | 120 | 12 HP |

<Warning>
  Cooking can fail at low levels, burning the food.
</Warning>

## Skill Data Files

Skill configuration is in `packages/shared/src/data/`:

| File | Purpose |
|------|---------|
| `equipment-requirements.json` | Level requirements for equipment |
| `equipment-stats.json` | Stat bonuses for equipment |

## Default Skill Values

Skills start at level 1 with 0 XP, except Constitution which starts at level 10:

```typescript
// From packages/shared/src/entities/player/PlayerEntity.ts (lines 111-123)
playerData.skills = {
  attack: { level: 1, xp: 0 },
  strength: { level: 1, xp: 0 },
  defense: { level: 1, xp: 0 },
  constitution: { level: 10, xp: 1154 },  // Starts at level 10
  ranged: { level: 1, xp: 0 },
  woodcutting: { level: 1, xp: 0 },
  fishing: { level: 1, xp: 0 },
  firemaking: { level: 1, xp: 0 },
  cooking: { level: 1, xp: 0 },
};
```

<Info>
  Constitution starts at level 10 (1,154 XP) like RuneScape's Hitpoints.
  Player health equals their Constitution level.
</Info>
