## Overview

Hyperscape features a RuneScape-inspired skill system with leveling, XP gain, and level requirements for equipment and activities.

## Available Skills

Hyperscape has **17 skills** total:

### Combat Skills

| Skill | Purpose |
|-------|---------|
| **Attack** | Melee accuracy, weapon requirements |
| **Strength** | Melee damage |
| **Defense** | Damage reduction, armor requirements |
| **Constitution** | Health points |
| **Ranged** | Ranged combat accuracy and damage |
| **Magic** | Spellcasting accuracy and damage |
| **Prayer** | Combat bonuses via prayers (trained by burying bones) |

### Gathering Skills

| Skill | Activity |
|-------|----------|
| **Woodcutting** | Chop trees for logs |
| **Mining** | Mine rocks for ores |
| **Fishing** | Catch fish at water spots |

### Artisan Skills

| Skill | Activity |
|-------|----------|
| **Firemaking** | Create fires from logs |
| **Cooking** | Prepare food from raw fish |
| **Smithing** | Smelt ores into bars and smith equipment |
| **Crafting** | Create leather armor, dragonhide, jewelry, and cut gems |
| **Fletching** | Create bows, arrows, and arrow components |
| **Runecrafting** | Convert essence into runes at mystical altars |

### Support Skills

| Skill | Activity |
|-------|----------|
| **Agility** | Movement and shortcuts (future) |

## XP and Leveling

### XP Formula

Hyperscape uses RuneScape's XP curve:

```
XP for Level N = floor(sum(floor(L + 300 * 2^(L/7))) / 4) for L = 1 to N-1
```

### Level Milestones

| 20 | 4,470 |

### Mining

Requirements:
- Pickaxe in inventory or equipped
- Click ore rock to mine

**OSRS-Accurate Mechanics:**
- Pickaxe tier affects **roll frequency** (not success rate)
- Success rate is **level-only** (pickaxe doesn't affect it)
- Rocks have **100% depletion** on successful mine (1/8 chance)
- Dragon/Crystal pickaxes have **bonus speed rolls**

| Ore | Level | XP | Depletion |
|-----|-------|-----|-----------| 
| Copper/Tin | 1 | 17.5 | 1/8 chance |
| Iron | 15 | 35 | 1/8 chance |
| Coal | 30 | 50 | 1/8 chance |
| Mithril | 55 | 80 | 1/8 chance |
| Adamantite | 70 | 95 | 1/8 chance |
| Runite | 85 | 125 | 1/8 chance |

**Pickaxe Tiers:**

| Pickaxe | Level | Roll Ticks | Bonus Speed |
|---------|-------|------------|-------------|
| Bronze | 1 | 8 ticks | None |
| Iron | 1 | 7 ticks | None |
| Steel | 6 | 6 ticks | None |
| Mithril | 21 | 5 ticks | None |
| Adamant | 31 | 4 ticks | None |
| Rune | 41 | 3 ticks | None |
| Dragon | 61 | 3 ticks | 1/6 chance for 2 ticks |
| Crystal | 71 | 3 ticks | 1/4 chance for 2 ticks |

<Info>
  Dragon and Crystal pickaxes have a chance to mine faster: Dragon has a 1/6 chance for 2-tick rolls (avg 2.83 ticks), Crystal has a 1/4 chance (avg 2.75 ticks).
</Info>

#### Tanning System

Convert hides to leather at tanner NPCs for a coin fee.

| Hide | Output | Cost | Location |
|------|--------|------|----------|
| Cowhide | Leather | 1 gp | Tanner NPC |
| Green dragonhide | Green dragon leather | 20 gp | Tanner NPC |
| Blue dragonhide | Blue dragon leather | 20 gp | Tanner NPC |
| Red dragonhide | Red dragon leather | 20 gp | Tanner NPC |
| Black dragonhide | Black dragon leather | 20 gp | Tanner NPC |

<Info>
  Tanning is instant (no XP granted). It's a service provided by NPCs to convert hides into usable leather for crafting.
</Info>

**Crafting Mechanics:**
- **Thread Consumption**: Thread has 5 uses before being consumed
- **Tick-Based**: Each craft takes 2-3 ticks (1.2-1.8 seconds)
- **Movement Cancellation**: Walking or entering combat cancels crafting
- **Make-X**: Craft multiple items in one session with quantity memory
- **Recipe Filtering**: Recipes filter by input item (e.g., chisel + uncut sapphire shows only sapphire)
- **Auto-Select**: Single recipe auto-selects to skip to quantity selection

## Prayer System

Prayer provides combat bonuses at the cost of draining prayer points:

**Training:**
- Bury bones for Prayer XP (4.5 XP for regular bones)
- Right-click bones in inventory → "Bury"
- 2-tick (1.2s) delay between burials

**Prayer Points:**
- Maximum points = Prayer level (1-99)
- Drain while prayers are active
- Recharge at altars (purple boxes in world)

**Available Prayers:**
- **Thick Skin** (Level 1): +5% Defense
- **Burst of Strength** (Level 4): +5% Strength
- **Clarity of Thought** (Level 7): +5% Attack
- **Rock Skin** (Level 10): +10% Defense
- **Superhuman Strength** (Level 13): +10% Strength

<Info>
  See [Prayer System](/wiki/game-systems/prayer) for complete mechanics, drain formulas, and combat integration.
</Info>

## Default Skill Values

Skills start at level 1 with 0 XP, except Constitution which starts at level 10:

```typescript
// From packages/shared/src/entities/player/PlayerEntity.ts
playerData.skills = {
  attack: { level: 1, xp: 0 },
  strength: { level: 1, xp: 0 },
  defense: { level: 1, xp: 0 },
  constitution: { level: 10, xp: 1154 },  // Starts at level 10
  ranged: { level: 1, xp: 0 },
  magic: { level: 1, xp: 0 },
  prayer: { level: 1, xp: 0 },
  woodcutting: { level: 1, xp: 0 },
  mining: { level: 1, xp: 0 },
  fishing: { level: 1, xp: 0 },
  firemaking: { level: 1, xp: 0 },
  cooking: { level: 1, xp: 0 },
  smithing: { level: 1, xp: 0 },
  agility: { level: 1, xp: 0 },
  crafting: { level: 1, xp: 0 },
};
```

<Info>
  Constitution starts at level 10 (1,154 XP) like RuneScape's Hitpoints.
  Player health equals their Constitution level.
</Info>
