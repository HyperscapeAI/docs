## Overview

Hyperscape features a RuneScape-inspired skill system with leveling, XP gain, and level requirements for equipment and activities.

## Available Skills

Hyperscape has **12 skills** total:

### Combat Skills

| Skill | Purpose |
|-------|---------|
| **Attack** | Melee accuracy, weapon requirements |
| **Strength** | Melee damage |
| **Defense** | Damage reduction, armor requirements |
| **Constitution** | Health points |
| **Prayer** | Protection prayers and combat buffs |

### Gathering Skills

| Skill | Activity |
|-------|----------|
| **Woodcutting** | Chop trees for logs |
| **Mining** | Mine rocks for ores |
| **Fishing** | Catch fish at water spots |

### Artisan Skills

| Skill | Activity |
|-------|----------|
| **Firemaking** | Create fires from logs |
| **Cooking** | Prepare food from raw fish |
| **Smithing** | Smelt ores into bars and smith equipment |

#### Support Skills

| Skill | Activity |
|-------|----------|
| **Agility** | Traverse the world to gain XP and improve stamina regeneration |

## Agility System

Agility is a unique skill that rewards exploration and movement. Unlike traditional RuneScape agility courses, Hyperscape's agility system integrates with the stamina and weight mechanics.

### Training Agility

**XP Gain**: Earn 1 XP per 2 tiles traveled (batched at 100 tiles = 50 XP)

- Walking or running both grant XP
- XP drops appear every ~15 seconds while running, ~30 seconds while walking
- Teleportation does not grant agility XP
- Death resets accumulated tile progress (but not earned XP)

**XP Rates**:

| Movement | Tiles/Second | XP/Minute |
|----------|--------------|-----------|
| Walking | 3.33 | ~100 XP |
| Running | 6.67 | ~200 XP |

### Agility Benefits

**Stamina Regeneration Bonus**: +1% stamina regen per agility level

| Agility Level | Idle Regen/Sec | Walking Regen/Sec |
|---------------|----------------|-------------------|
| 1 | 4.04 | 2.02 |
| 10 | 4.40 | 2.20 |
| 25 | 5.00 | 2.50 |
| 50 | 6.00 | 3.00 |
| 75 | 7.00 | 3.50 |
| 99 | 7.96 | 3.98 |

<Info>
  Higher agility levels allow you to recover stamina nearly twice as fast, making it easier to maintain running speed during long journeys.
</Info>

### Weight and Stamina

**Weight-Based Stamina Drain**: +0.5% drain per kg carried

| Weight (kg) | Drain Multiplier | Drain/Second |
|-------------|------------------|--------------|
| 0 | 1.0x | 2.0 |
| 10 | 1.05x | 2.1 |
| 20 | 1.1x | 2.2 |
| 50 | 1.25x | 2.5 |
| 100 | 1.5x | 3.0 |

<Warning>
  Carrying heavy loads significantly increases stamina drain while running. Manage your inventory weight for optimal travel efficiency.
</Warning>

### Agility Unlocks

|-------|--------|

| 10 | +10% stamina regeneration |

## XP and Leveling

### XP Formula

Hyperscape uses RuneScape's XP curve:

```
XP for Level N = floor(sum(floor(L + 300 * 2^(L/7))) / 4) for L = 1 to N-1
```

### Level Milestones

| Level | Total XP |
|-------|----------|
| 10 | 1,154 |
| 20 | 4,470 |
| 30 | 13,363 |
| 50 | 101,333 |
| 70 | 737,627 |
| 99 | 13,034,431 |

## Resource Gathering

### Woodcutting

Requirements:
- Hatchet in inventory or equipped
- Click tree to chop

Success rate improves with level. Higher-level trees require higher Woodcutting levels.

| Tree | Level | XP |
|------|-------|-----|
| Normal | 1 | 25 |
| Oak | 15 | 37.5 |
| Willow | 30 | 67.5 |
| Yew | 60 | 175 |
| Magic | 75 | 250 |

### Mining

Requirements:
- Pickaxe in inventory or equipped
- Click ore rock to mine

**OSRS-Accurate Mechanics:**
- Pickaxe tier affects **roll frequency** (not success rate)
- Success rate is **level-only** (pickaxe doesn't affect it)
- Rocks have **100% depletion** on successful mine (1/8 chance)
- Dragon/Crystal pickaxes have **bonus speed rolls**

| Ore | Level | XP | Depletion |
|-----|-------|-----|-----------|
| Copper/Tin | 1 | 17.5 | 1/8 chance |
| Iron | 15 | 35 | 1/8 chance |
| Coal | 30 | 50 | 1/8 chance |
| Mithril | 55 | 80 | 1/8 chance |
| Adamantite | 70 | 95 | 1/8 chance |
| Runite | 85 | 125 | 1/8 chance |

**Pickaxe Tiers:**

| Pickaxe | Level | Roll Ticks | Bonus Speed |
|---------|-------|------------|-------------|
| Bronze | 1 | 8 ticks | None |
| Iron | 1 | 7 ticks | None |
| Steel | 6 | 6 ticks | None |
| Mithril | 21 | 5 ticks | None |
| Adamant | 31 | 4 ticks | None |
| Rune | 41 | 3 ticks | None |
| Dragon | 61 | 3 ticks | 1/6 chance for 2 ticks |
| Crystal | 71 | 3 ticks | 1/4 chance for 2 ticks |

<Info>
  Dragon and Crystal pickaxes have a chance to mine faster: Dragon has a 1/6 chance for 2-tick rolls (avg 2.83 ticks), Crystal has a 1/4 chance (avg 2.75 ticks).
</Info>

### Smithing

Smelt ores into bars at furnaces, then smith bars into equipment at anvils.

#### Smelting (at Furnace)

| Bar | Level | Ores Required | XP | Success Rate |
|-----|-------|---------------|-----|--------------|
| Bronze | 1 | 1 Copper + 1 Tin | 6.25 | 100% |
| Iron | 15 | 1 Iron Ore | 12.5 | 50% |
| Steel | 30 | 1 Iron Ore + 2 Coal | 17.5 | 100% |
| Mithril | 50 | 1 Mithril Ore + 4 Coal | 30 | 100% |
| Adamant | 70 | 1 Adamantite Ore + 6 Coal | 37.5 | 100% |
| Rune | 85 | 1 Runite Ore + 8 Coal | 50 | 100% |

<Info>
  Iron ore has a 50% failure rate when smelting, matching OSRS mechanics.
</Info>

#### Smithing (at Anvil)

Click an anvil to open the smithing interface. **Requires a hammer in your inventory** (not consumed). Select the item to smith and quantity.

## Default Skill Values

Skills start at level 1 with 0 XP, except Constitution which starts at level 10:

```typescript
// From packages/shared/src/entities/player/PlayerEntity.ts
playerData.skills = {
  attack: { level: 1, xp: 0 },
  strength: { level: 1, xp: 0 },
  defense: { level: 1, xp: 0 },
  constitution: { level: 10, xp: 1154 },  // Starts at level 10
  prayer: { level: 1, xp: 0 },
  woodcutting: { level: 1, xp: 0 },
  mining: { level: 1, xp: 0 },
  fishing: { level: 1, xp: 0 },
  mining: { level: 1, xp: 0 },
  firemaking: { level: 1, xp: 0 },
  cooking: { level: 1, xp: 0 },
  smithing: { level: 1, xp: 0 },
};
```

<Info>
  Constitution starts at level 10 (1,154 XP) like RuneScape's Hitpoints.
  Player health equals their Constitution level.
</Info>
