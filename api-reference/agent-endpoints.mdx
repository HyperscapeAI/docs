## Overview

The Agent API provides endpoints for controlling and monitoring AI agents in Hyperscape. These endpoints are used by the dashboard and can be integrated with external tools.

**Base URL**: `http://localhost:5555/api/agents` (development)

## Authentication

Most agent endpoints require authentication via Privy JWT token:

```bash
Authorization: Bearer <privy-jwt-token>
```

## Endpoints

### Get Agent Goal

Retrieve the current goal and available goals for an agent.

```http
GET /api/agents/:agentId/goal
```

**Response**:
```json
{
  "goal": {
    "type": "combat_training",
    "description": "Training combat at goblins",
    "target": "goblin",
    "progress": 15,
    "progressPercent": 30,
    "elapsedMs": 45000,
    "targetSkill": "attack",
    "locked": false,
    "lockedBy": null
  },
  "availableGoals": [
    {
      "id": "combat_training_goblins",
      "type": "combat_training",
      "description": "Train combat at goblins",
      "priority": 80
    }
  ],
  "goalsPaused": false
}
```

**Fields**:
- `goal`: Current active goal (null if none)
- `availableGoals`: Goals the agent can select
- `goalsPaused`: Whether autonomous goal selection is paused

---

### Set Agent Goal

Manually set a goal for an agent.

```http
POST /api/agents/:agentId/goal
Content-Type: application/json

{
  "goalId": "combat_training_goblins"
}
```

**Response**:
```json
{
  "success": true,
  "goal": {
    "type": "combat_training",
    "description": "Train combat at goblins",
    "locked": true,
    "lockedBy": "manual"
  }
}
```

**Behavior**:
- Sets goal and locks it (prevents autonomous override)
- Agent will pursue this goal until completed or manually changed
- Unlocks automatically when goal completes

---

### Stop Agent Goal

Stop the current goal and pause autonomous goal selection.

```http
POST /api/agents/:agentId/goal/stop
```

**Response**:
```json
{
  "success": true,
  "message": "Goal stopped and paused"
}
```

**Behavior**:
- Cancels current movement path
- Clears active goal
- Sets `goalsPaused = true`
- Blocks `SET_GOAL` actions (agent forced to IDLE)
- Chat commands still work normally
- Agent returns to idle after completing chat commands

**Implementation Details**:
- Sends `goalOverride` packet with `stop: true`
- 100ms acknowledgment delay for processing
- Pause state persists across reconnections

---

### Resume Agent Goals

Resume autonomous goal selection after stopping.

```http
POST /api/agents/:agentId/goal/resume
```

**Response**:
```json
{
  "success": true,
  "message": "Goals resumed"
}
```

**Behavior**:
- Clears `goalsPaused` flag
- Agent will select new goal on next tick
- Autonomous behavior resumes normally

---

### Send Message to Agent

Send a chat message or command to an agent.

```http
POST /api/agents/:agentId/message
Content-Type: application/json

{
  "content": "pick up bronze pickaxe",
  "userId": "user-123"
}
```

**Response**:
```json
{
  "success": true,
  "message": "Message sent to agent"
}
```

**Behavior**:
- Message is processed by ElizaOS runtime
- Agent selects appropriate action based on message
- Response appears in game chat
- Dashboard chat panel opens automatically

## Rate Limiting

**Global Limit**: 100 requests per minute per IP

**Dashboard Polling**:
- Goal updates: Every 10 seconds
- Skills updates: Every 10 seconds
- Position updates: Every 5-10 seconds
- Activity updates: Every 10 seconds

**Retry Logic**: Dashboard uses exponential backoff (1s → 2s → 4s) with max 3 retries.

## WebSocket Events

Agents can subscribe to real-time events via WebSocket:

```typescript
// Connect to agent WebSocket
const ws = new WebSocket('ws://localhost:5555/ws');

// Listen for goal updates
ws.on('goalUpdated', (data) => {
  console.log('Goal changed:', data.goal);
});

// Listen for skill XP gains
ws.on('skillsUpdated', (data) => {
  console.log('Skills updated:', data.skills);
});
```

**Available Events**:
- `goalUpdated`: Goal changed
- `skillsUpdated`: Skill levels/XP changed
- `inventoryUpdated`: Inventory changed
- `equipmentUpdated`: Equipment changed
- `playerWeightUpdated`: Inventory weight changed (for stamina calculations)
