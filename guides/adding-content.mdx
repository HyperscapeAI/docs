## Manifest-Driven Design

Hyperscape uses JSON manifests for game content. Add new NPCs, items, stores, and world areas by editing JSON files in `packages/server/world/assets/manifests/`.

<Info>
  No code changes required—just edit the JSON manifest files and restart the server.
</Info>

## Content Files

All manifests are in `packages/server/world/assets/manifests/`:

### Core Manifests

| File | Purpose |
|------|---------|
| `npcs.json` | NPC and mob definitions |
| `avatars.json` | Character models |
| `banks-stores.json` | Shop inventories |
| `world-areas.json` | Zone configuration |
| `tier-requirements.json` | Tier-based level requirements |
| `skill-unlocks.json` | Skill unlock descriptions |

### Item Manifests (Directory)

Items are organized by category in `items/` directory:

| File | Purpose |
|------|---------|
| `items/weapons.json` | Swords, axes, bows, etc. |
| `items/tools.json` | Hatchets, pickaxes, fishing rods, hammer |
| `items/resources.json` | Ores, bars, logs, fish |
| `items/food.json` | Cooked food, raw food, burnt food |
| `items/misc.json` | Coins, junk items, quest items |

### Recipe Manifests (Directory)

Processing skill recipes in `recipes/` directory:

| File | Purpose |
|------|---------|
| `recipes/cooking.json` | Raw → cooked food recipes |
| `recipes/firemaking.json` | Log burning data |
| `recipes/smelting.json` | Ore → bar recipes |
| `recipes/smithing.json` | Bar → equipment recipes |

### Gathering Manifests (Directory)

Resource gathering data in `gathering/` directory:

| File | Purpose |
|------|---------|
| `gathering/woodcutting.json` | Tree types and locations |
| `gathering/mining.json` | Rock types and ore data |
| `gathering/fishing.json` | Fishing spot types |

## Adding NPCs

NPCs are defined with combat stats, drops, and spawn locations:

```typescript
{
  id: "goblin",
  name: "Goblin",
  combatLevel: 2,
  stats: {
    attack: 1,
    strength: 1,
    defense: 1,
    constitution: 5
  },
  aggressive: true,
  aggroRange: 3,
  drops: [
    { itemId: "coins", quantity: [1, 10], chance: 1.0 },
    { itemId: "bronze_sword", quantity: 1, chance: 0.05 }
  ],
  respawnTime: 15000
}
```

### Difficulty Levels

| Level | Examples |
|-------|----------|
| 1 | Goblins, Bandits, Barbarians |
| 2 | Hobgoblins, Guards, Dark Warriors |
| 3 | Black Knights, Ice Warriors, Dark Rangers |

## Adding Items

Items include equipment, resources, and consumables:

```typescript
{
  id: "bronze_sword",
  name: "Bronze Sword",
  type: "weapon",
  slot: "weapon",
  requirements: { attack: 1 },
  stats: { attackBonus: 4, strengthBonus: 3 },
  tradeable: true,
  stackable: false
}
```

### Item Types

- **weapon**: Swords, bows
- **armor**: Helmets, bodies, legs
- **tool**: Hatchets, fishing rods
- **consumable**: Food, potions
- **resource**: Logs, fish, ores

## Adding Shops

Shops define available items and prices:

```typescript
{
  id: "general_store",
  name: "General Store",
  items: [
    { itemId: "bronze_hatchet", stock: 10, price: 50 },
    { itemId: "fishing_rod", stock: 10, price: 25 },
    { itemId: "tinderbox", stock: 10, price: 15 }
  ]
}
```

## Adding World Areas

World areas define zones with biomes and mob spawns:

```typescript
{
  id: "mistwood_valley",
  name: "Mistwood Valley",
  biome: "forest",
  difficulty: 1,
  spawns: [
    { npcId: "goblin", count: 5 },
    { npcId: "bandit", count: 3 }
  ],
  resources: [
    { type: "tree", count: 10 },
    { type: "fishing_spot", count: 2 }
  ]
}
```

### Biomes

- Mistwood Valley (foggy forest)
- Goblin Wastes (barren lands)
- Darkwood Forest (dense shadows)
- Northern Reaches (frozen tundra)
- Blasted Lands (corrupted areas)

## Testing Changes

2. Save (hot reload applies)
