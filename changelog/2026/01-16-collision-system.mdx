## Static Tile Collision (PR #552)

*Merged: January 15, 2026 | +3,691 lines | Author: dreaminglucid*

Zone-based collision system for static world objects:

### CollisionMatrix
- Bitmask constants for collision flags
- Zone-based tile storage (8×8 tile zones)
- Lazy allocation for memory efficiency
- O(1) tile lookups

### Collision Flags
- Static objects: BLOCKED, WATER, STEEP_SLOPE
- Entity occupancy: OCCUPIED_PLAYER, OCCUPIED_NPC
- Directional walls for future dungeons/buildings

### Integration
- Resources and stations register static collision
- Mob pathfinding respects CollisionMatrix
- Unified `isTileWalkable` method in TerrainSystem
- Network serialization for zone collision sync

### Build System
- Auto-detect station footprints from model bounds at build time
- Auto-generate `model-bounds.json` during build/dev
- Turbo caching for incremental builds

### Multi-Tile Stations
- Interaction enabled from any side of multi-tile stations
- Center-based footprint registration for resources

### Testing
- Unit tests for CollisionMatrix, CollisionFlags, and tilesWithinRangeOfFootprint

## Prayer System (PR #563)

*Merged: January 16, 2026 | +4,126 lines | Author: dreaminglucid*

Complete prayer skill implementation:

### Features
- Manifest-driven prayer types with Skills integration
- Database schema and migration for persistence
- PrayerDataProvider for manifest data loading

- Prayer bonuses integrated into combat damage calculations

### Bone Burying
- Regular, big, and dragon bones support
- 2-tick delay for OSRS accuracy
- Prayer XP rewards

### Prayer Altars
- Altar entities for recharging prayer points
- Client-side handling with visible purple material

### UI
- Prayer panel with server state sync
- Real-time prayer point updates via events
- Chat messages for prayer failures

### Testing
