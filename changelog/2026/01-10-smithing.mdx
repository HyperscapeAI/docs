## Smithing Skill (PR #492)

*Merged: January 9, 2026 | +6,682 / -622 lines | 31 commits | Author: dreaminglucid*

Complete smithing skill implementation with OSRS-accurate mechanics:

### Smelting (Furnaces)
- Convert ores into bars at FurnaceEntity world objects
- Tier-specific XP rewards per bar
- Manifest-driven recipes via ProcessingDataProvider

### Smithing (Anvils)
- Convert bars into equipment at AnvilEntity world objects
- Full UI with Make X memory
- Level requirements display with greyed-out unavailable options

### OSRS-Accurate Timing
- Tick-based processing system matching OSRS mechanics
- Timing defined in manifest for easy tuning

### Database Persistence
- New smithingLevel and smithingXp columns
- Level/XP saved and loaded on player login

### Architecture
- SmeltingSystem and SmithingSystem integrated into SystemLoader
- Furnace/anvil interaction handlers
- WebSocket handlers for smelting/smithing requests

### Performance
- Memory leak fixes in playerSkills cache
- Pre-allocated inventory count buffer to reduce GC pressure
- Server-only guards to prevent client-side event subscriptions
- Cleanup of setTimeout references to prevent orphaned callbacks

### Security
- Input validation and centralized constants
- Type guards for inventory item validation
- Rate limiting on network handlers

### Testing
- ProcessingDataProvider unit tests for smelting/smithing data lookups

### Bonus Fixes
- Firemaking level requirement validation added
- Cooking level requirement check before starting action

## Context Menu Colors (PR #497)

*Merged: January 10, 2026*

OSRS-style context menus with colored entity names:

### Color Coding
- Orange (#ff9040) for items
- Yellow (#ffff00) for NPCs
- Cyan (#00ffff) for objects

### Inventory Actions
- Manifest-driven actions with heuristic fallback
- Items can define `inventoryActions` array
- First action becomes left-click default
- Supported: Eat, Drink, Wield, Wear, Bury, Use, Drop, Examine

### Architecture
- Centralized InventoryActionDispatcher
- Item helper utilities: isFood, isPotion, isBone, usesWield, usesWear
- Cancel option always shown last

## Food & Eating System (PR #500)

*Merged: January 10, 2026*

OSRS-accurate food consumption with eat delay:

- 3-tick (1.8s) cooldown between foods
- Eating during combat adds 3 ticks to attack cooldown
- Server-authoritative with full validation
- EatDelayManager for per-player cooldown tracking
- Food consumed even at full health (OSRS-accurate)
- Event-driven health bar updates via PLAYER_HEALTH_UPDATED
