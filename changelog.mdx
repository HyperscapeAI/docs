<Update label="January 9, 2026" description="Manifest Refactor & Automation" date="2026-01-09">

### 🔄 Manifest System Refactor (PR #3)

Major reorganization of the manifest system for better scalability:

**New Directory Structure:**
- `items/` — Split by type (weapons, tools, resources, food, misc)
- `gathering/` — Woodcutting, mining, fishing data
- `recipes/` — Smelting, smithing, cooking, firemaking

**New Centralized Files:**
- `tier-requirements.json` — OSRS-accurate level requirements
- `skill-unlocks.json` — Skill progression milestones

**Benefits:**
- Better organization and maintainability
- Easier to find and edit specific content
- Clearer separation of concerns
- More scalable for future content additions

### 🍄 New Vegetation (PR #4)

Added mushroom vegetation to biomes:
- Configurable density and clustering
- Biome-specific spawn parameters
- Reduced tree density in plains biome (8 → 5)

### 🤖 GitHub Actions (PR #2)

Automated workflows for code quality:
- **Claude Code Review** — Automatic PR reviews
- **Claude PR Assistant** — Responds to `@claude` mentions
- **Documentation Updates** — Auto-updates docs on manifest changes

<Update label="v0.1.0" description="Initial Release" date="2025-01-01">

### 🎮 Core Features
- **Tick-based Combat** — Authentic OSRS-style 600ms tick combat system
- **AI Agents** — ElizaOS integration with 17 actions and 6 state providers
- **Skill System** — Attack, Strength, Defense, Constitution, Ranged, Woodcutting, Fishing, Firemaking, Cooking
- **Economy** — Banks, shops, inventory, and loot system

### 🏗️ Architecture
- Turbo monorepo with 7 packages
- Three.js + PhysX WASM for 3D physics
- Fastify + WebSocket multiplayer
- React 19 + Vite client

### 📦 Packages
- `@hyperscape/shared` — Core 3D engine
- `@hyperscape/server` — Game server
- `@hyperscape/client` — Web client
- `@hyperscape/plugin-hyperscape` — ElizaOS plugin
- `@hyperscape/physx-js-webidl` — PhysX bindings
- `3d-asset-forge` — AI asset generation

[View release on GitHub](https://github.com/HyperscapeAI/hyperscape/releases/tag/v0.1.0)
