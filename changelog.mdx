<Update label="Latest" description="Smithing Skill & CI Improvements" date="2025-01-09">

### ⚒️ Smithing Skill (PR #492)
- **Full smithing implementation** — Smelt ores into bars at furnaces, smith bars into equipment at anvils
- **OSRS-accurate mechanics** — Tick-based processing (4 ticks per action), iron smelting 50% success rate
- **UI panels** — Dedicated smelting and smithing interfaces with quantity selection (1, 5, 10, All, X)
- **Recipe system** — Manifest-driven recipes for bars and equipment across all metal tiers
- **Level requirements** — Bronze (1), Iron (15), Steel (30), Mithril (50), Adamant (70), Rune (85)
- **Database migration** — Added smithingLevel and smithingXp columns to character table
- **Skill unlocks** — Integrated with skill progression system and level-up notifications

### 🤖 Claude GitHub Actions (PR #493)
- **Code review workflow** — Automated Claude code reviews on pull requests
- **PR assistant** — @claude mentions in comments trigger AI assistance
- **CI integration** — Claude can read CI results and provide context-aware help

### 🏗️ Architecture Improvements
- **Manifest-driven data** — Items split into category files (weapons, tools, resources, food, misc)
- **Tier-based requirements** — Centralized tier requirements system for equipment and tools
- **Processing data provider** — Unified system for cooking, firemaking, smelting, and smithing recipes
- **Rate limiting** — Added request throttling to smelting/smithing network handlers

### 🐛 Bug Fixes
- Fixed firemaking level requirement validation
- Fixed cooking level requirement checks before starting actions
- Corrected firemaking event payload shape
- Updated test item counts to match current manifests

</Update>

<Update label="v0.1.0" description="Initial Release" date="2025-01-01">

### 🎮 Core Features
- **Tick-based Combat** — Authentic OSRS-style 600ms tick combat system
- **AI Agents** — ElizaOS integration with 17 actions and 6 state providers
- **Skill System** — 11 skills: Combat (Attack, Strength, Defense, Constitution, Ranged, Prayer), Gathering (Woodcutting, Fishing, Mining), Artisan (Firemaking, Cooking, Smithing)
- **Economy** — Banks, shops, inventory, and loot system

### 🏗️ Architecture
- Turbo monorepo with 7 packages
- Three.js + PhysX WASM for 3D physics
- Fastify + WebSocket multiplayer
- React 19 + Vite client

### 📦 Packages
- `@hyperscape/shared` — Core 3D engine
- `@hyperscape/server` — Game server
- `@hyperscape/client` — Web client
- `@hyperscape/plugin-hyperscape` — ElizaOS plugin
- `@hyperscape/physx-js-webidl` — PhysX bindings
- `3d-asset-forge` — AI asset generation

[View release on GitHub](https://github.com/HyperscapeAI/hyperscape/releases/tag/v0.1.0)

</Update>
