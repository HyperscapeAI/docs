# Social System

Hyperscape features a comprehensive social system with friend management, private messaging, online status tracking, and ignore lists.

<Info>
Social code lives in `packages/server/src/systems/ServerNetwork/handlers/friends.ts` (server) and `packages/client/src/systems/client/SocialSystem.ts` (client).
</Info>

## Core Features

- **Friend Management** — Send, accept, decline, and remove friend requests
- **Online Status** — Real-time tracking of friend online/offline status
- **Private Messaging** — Direct messages between players
- **Ignore List** — Block unwanted players
- **Friend List Sync** — Automatic synchronization on login

## Friend Management

### Friend Request Flow

1. **Send Request**

```typescript
// Client sends friend request
world.network.send("friendRequest", { targetUsername: "PlayerName" });

// Server validates and creates request
await db.insert(schema.friendRequests).values({
  senderId: playerId,
  receiverId: targetId,
  status: "pending",
  createdAt: new Date(),
});

// Notify recipient if online
if (recipientSocket) {
  sendToSocket(recipientSocket, "friendRequestReceived", {
    requestId,
    fromPlayerId: playerId,
    fromUsername: senderName,
  });
}
```

2. **Accept Request**

```typescript
// Client accepts request
world.network.send("friendRequestRespond", {
  requestId: requestId,
  accept: true,
});

// Server creates bidirectional friendship
await db.transaction(async (tx) => {
  // Update request status
  await tx.update(schema.friendRequests)
    .set({ status: "accepted" })
    .where(eq(schema.friendRequests.id, requestId));
  
  // Create friendship entries (bidirectional)
  await tx.insert(schema.friendships).values([
    { playerId: senderId, friendId: receiverId },
    { playerId: receiverId, friendId: senderId },
  ]);
});

// Notify both players
sendToSocket(senderSocket, "friendAdded", { friendId: receiverId, username: receiverName });
sendToSocket(receiverSocket, "friendAdded", { friendId: senderId, username: senderName });
```

3. **Decline Request**

```typescript
// Client declines request
world.network.send("friendRequestRespond", {
  requestId: requestId,
  accept: false,
});

// Server updates request status
await db.update(schema.friendRequests)
  .set({ status: "declined" })
  .where(eq(schema.friendRequests.id, requestId));

// Notify sender
sendToSocket(senderSocket, "friendRequestDeclined", {
  username: receiverName,
});
```

### Remove Friend

```typescript
// Client removes friend
world.network.send("friendRemove", { friendId: friendId });

// Server deletes both friendship entries
await db.transaction(async (tx) => {
  await tx.delete(schema.friendships)
    .where(
      or(
        and(
          eq(schema.friendships.playerId, playerId),
          eq(schema.friendships.friendId, friendId)
        ),
        and(
          eq(schema.friendships.playerId, friendId),
          eq(schema.friendships.friendId, playerId)
        )
      )
    );
});

// Notify both players
sendToSocket(playerSocket, "friendRemoved", { friendId });
sendToSocket(friendSocket, "friendRemoved", { friendId: playerId });
```

## Online Status Tracking

### Status Synchronization

When a player connects, the server:

1. Loads friend list from database
2. Checks which friends are currently online
3. Sends friend list with online status to player
4. Notifies online friends that player is now online

```typescript
// From packages/server/src/systems/ServerNetwork/handlers/friends.ts
async function syncFriendListOnConnect(playerId: string, socket: ServerSocket): Promise<void> {
  // Load friendships from database
  const friendships = await db.query.friendships.findMany({
    where: eq(schema.friendships.playerId, playerId),
  });
  
  // Check online status for each friend
  const friendList = friendships.map(friendship => ({
    friendId: friendship.friendId,
    username: getFriendUsername(friendship.friendId),
    isOnline: isPlayerOnline(friendship.friendId),
  }));
  
  // Send friend list to player
  sendToSocket(socket, "friendListSync", { friends: friendList });
  
  // Notify online friends that player is now online
  for (const friend of friendships) {
    if (isPlayerOnline(friend.friendId)) {
      const friendSocket = getSocketByPlayerId(world, friend.friendId);
      if (friendSocket) {
        sendToSocket(friendSocket, "friendOnline", {
          friendId: playerId,
          username: getPlayerName(world, playerId),
        });
      }
    }
  }
}
```

### Status Change Events

| Event | Trigger | Data |
|-------|---------|------|
| `friendOnline` | Friend connects | `friendId`, `username` |
| `friendOffline` | Friend disconnects | `friendId` |
| `friendListSync` | Player connects | `friends[]` with online status |

## Private Messaging

### Send Private Message

```typescript
// Client sends private message
world.network.send("privateMessage", {
  targetPlayerId: friendId,
  message: "Hello!",
});

// Server validates and delivers
async function handlePrivateMessage(
  socket: ServerSocket,
  data: { targetPlayerId: string; message: string },
  world: World,
): Promise<void> {
  const senderId = getPlayerId(socket);
  
  // Validate friendship exists
  const friendship = await db.query.friendships.findFirst({
    where: and(
      eq(schema.friendships.playerId, senderId),
      eq(schema.friendships.friendId, data.targetPlayerId)
    ),
  });
  
  if (!friendship) {
    sendToSocket(socket, "error", { message: "Not friends with that player" });
    return;
  }
  
  // Check if sender is ignored by recipient
  const isIgnored = await db.query.ignoredPlayers.findFirst({
    where: and(
      eq(schema.ignoredPlayers.playerId, data.targetPlayerId),
      eq(schema.ignoredPlayers.ignoredPlayerId, senderId)
    ),
  });
  
  if (isIgnored) {
    // Silently fail - don't reveal ignore status
    return;
  }
  
  // Deliver message if recipient is online
  const recipientSocket = getSocketByPlayerId(world, data.targetPlayerId);
  if (recipientSocket) {
    sendToSocket(recipientSocket, "privateMessageReceived", {
      fromPlayerId: senderId,
      fromUsername: getPlayerName(world, senderId),
      message: data.message,
      timestamp: Date.now(),
    });
  }
  
  // Confirm delivery to sender
  sendToSocket(socket, "privateMessageSent", {
    toPlayerId: data.targetPlayerId,
    message: data.message,
  });
}
```

## Ignore List

### Add to Ignore List

```typescript
// Client ignores player
world.network.send("ignorePlayer", { targetPlayerId: playerId });

// Server adds to ignore list
await db.insert(schema.ignoredPlayers).values({
  playerId: playerId,
  ignoredPlayerId: targetId,
  createdAt: new Date(),
});

// Ignored players:
// - Cannot send private messages
// - Cannot send friend requests
// - Cannot send trade requests
```

### Remove from Ignore List

```typescript
// Client unignores player
world.network.send("unignorePlayer", { targetPlayerId: playerId });

// Server removes from ignore list
await db.delete(schema.ignoredPlayers)
  .where(
    and(
      eq(schema.ignoredPlayers.playerId, playerId),
      eq(schema.ignoredPlayers.ignoredPlayerId, targetId)
    )
  );
```

## Database Schema

### Friendships Table

```sql
CREATE TABLE friendships (
  id SERIAL PRIMARY KEY,
  "playerId" TEXT NOT NULL,
  "friendId" TEXT NOT NULL,
  "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
  UNIQUE("playerId", "friendId")
);
```

### Friend Requests Table

```sql
CREATE TABLE friend_requests (
  id SERIAL PRIMARY KEY,
  "senderId" TEXT NOT NULL,
  "receiverId" TEXT NOT NULL,
  status TEXT NOT NULL,  -- 'pending', 'accepted', 'declined'
  "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
  UNIQUE("senderId", "receiverId")
);
```

### Ignored Players Table

```sql
CREATE TABLE ignored_players (
  id SERIAL PRIMARY KEY,
  "playerId" TEXT NOT NULL,
  "ignoredPlayerId" TEXT NOT NULL,
  "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
  UNIQUE("playerId", "ignoredPlayerId")
);
```

## Network Packets

### Client → Server

| Packet | Data | Description |
|--------|------|-------------|
| `friendRequest` | `targetUsername` | Send friend request |
| `friendRequestRespond` | `requestId`, `accept` | Accept/decline request |
| `friendRemove` | `friendId` | Remove friend |
| `privateMessage` | `targetPlayerId`, `message` | Send private message |
| `ignorePlayer` | `targetPlayerId` | Add to ignore list |
| `unignorePlayer` | `targetPlayerId` | Remove from ignore list |

### Server → Client

| Packet | Data | Description |
|--------|------|-------------|
| `friendListSync` | `friends[]` | Full friend list with online status |
| `friendRequestReceived` | `requestId`, `fromPlayerId`, `fromUsername` | Incoming friend request |
| `friendAdded` | `friendId`, `username` | Friend added successfully |
| `friendRemoved` | `friendId` | Friend removed |
| `friendOnline` | `friendId`, `username` | Friend came online |
| `friendOffline` | `friendId` | Friend went offline |
| `privateMessageReceived` | `fromPlayerId`, `fromUsername`, `message`, `timestamp` | Incoming private message |
| `privateMessageSent` | `toPlayerId`, `message` | Message sent confirmation |
| `friendRequestDeclined` | `username` | Friend request was declined |

## Security Features

### Ignore List Protection

Ignored players are blocked from:

```typescript
// Check if sender is ignored before delivering message
const isIgnored = await db.query.ignoredPlayers.findFirst({
  where: and(
    eq(schema.ignoredPlayers.playerId, recipientId),
    eq(schema.ignoredPlayers.ignoredPlayerId, senderId)
  ),
});

if (isIgnored) {
  // Silently fail - don't reveal ignore status to sender
  return;
}
```

### Friendship Validation

All social actions validate friendship status:

```typescript
// Private messages require friendship
const friendship = await db.query.friendships.findFirst({
  where: and(
    eq(schema.friendships.playerId, senderId),
    eq(schema.friendships.friendId, recipientId)
  ),
});

if (!friendship) {
  sendToSocket(socket, "error", { message: "Not friends with that player" });
  return;
}
```
