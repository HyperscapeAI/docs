## Overview

The trading system enables secure player-to-player item exchanges with OSRS-accurate two-screen confirmation flow, proximity checks, and comprehensive security features.

<Info>
  Trading code lives in `packages/server/src/systems/TradingSystem/` with modular handlers for each aspect of the trade flow.
</Info>

## Trade Flow

### Initiating a Trade

1. **Right-click** on another player
2. Select **"Trade with [Player]"** from context menu
3. If out of range, character auto-walks to player
4. Trade request sent when within 2 tiles

### Trade Request

The target player receives:
- Pink chat message: **"[Player] wishes to trade with you."**
- Clickable message to accept
- Trade request modal with Accept/Decline buttons

### Screen 1: Offer Items

Both players can:
- Click inventory items to add to offer
- Click offered items to remove
- Enter quantities for stackable items
- View partner's offer in real-time
- See partner's free inventory slots
- Click **"Accept"** when satisfied

**Interface Blocking:**
- Bank, store, and dialogue interfaces automatically close
- Prevents item duplication exploits
- Trade closes if player opens conflicting interface

### Screen 2: Final Confirmation

After both players accept on Screen 1:
- **Wealth Transfer Indicator** shows value difference
  - Green arrow: receiving more value
  - Red arrow: giving more value
  - Gray: balanced trade
- Review final offers (no changes allowed)
- Both players must click **"Accept"** again
- Trade completes when both confirm

**Reset Conditions:**
- Any item change resets both players to Screen 1
- Moving too far apart cancels trade
- Closing trade window cancels for both players

## Security Features

### Proximity Validation

```typescript
// From request.ts
const TRADE_RANGE = 2; // tiles

// Validated on:
// - Trade request initiation
// - Every item add/remove
// - Screen transitions
// - Trade completion

if (distance > TRADE_RANGE) {
  cancelTrade(playerId);
  sendMessage(playerId, "You are too far away to trade.");
}
```

### Transaction Safety

- **Atomic Operations**: Trade completes or fully rolls back
- **Inventory Checks**: Validates space before accepting
- **Item Verification**: Confirms items exist before transfer
- **Rollback on Failure**: Restores state if any step fails

## Error Handling

### Common Errors

| Error | Cause | Resolution |
|-------|-------|------------|
| "Too far away" | Distance > 2 tiles | Move closer to partner |
| "Not enough space" | Inventory full | Free up inventory slots |
| "Item no longer available" | Item removed during trade | Re-add item to offer |
| "Trade cancelled" | Partner declined/moved | Initiate new trade |

### Validation

```typescript
// From helpers.ts
export function validateTradeCompletion(trade: Trade): ValidationResult {
  // Check both players have space
  if (!hasInventorySpace(trade.player1, trade.player2Offer)) {
    return { valid: false, reason: "Player 1 inventory full" };
  }
  
  // Verify all items still exist
  if (!verifyItemsExist(trade.player1, trade.player1Offer)) {
    return { valid: false, reason: "Items no longer available" };
  }
  
  // Check proximity
  if (getDistance(trade.player1, trade.player2) > TRADE_RANGE) {
    return { valid: false, reason: "Players too far apart" };
  }
  
  return { valid: true };
}
```
