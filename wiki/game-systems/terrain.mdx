## Overview

Hyperscape's terrain system generates a procedurally-generated island world with natural coastline variation, elevation, and water features. The terrain uses multi-octave noise for realistic geographical features while maintaining gameplay-friendly elevation for resource spawning.

Terrain code lives in `packages/shared/src/systems/shared/world/TerrainSystem.ts`.

## Island Configuration

The world is generated as an island with configurable parameters:

```typescript
const ISLAND_RADIUS = 220;      // Base radius: ~220m (~440m diameter)
const ISLAND_FALLOFF = 60;      // Transition zone width (beach/shore)
const POND_RADIUS = 50;         // Pond radius
const POND_DEPTH = 0.55;        // Pond depth (normalized)
```

### Island Features

| Feature | Description |
|---------|-------------|
| **Base Radius** | 220m (~440m diameter island) |
| **Falloff Zone** | 60m smooth transition from land to ocean |
| **Pond** | 50m radius pond offset from center (-80, 60) |
| **Ocean Floor** | 0.05 normalized height (~1.5m depth) |
| **Base Elevation** | 0.42 normalized (~12.6m above sea level) |

## Natural Coastline Generation

The coastline uses multi-octave noise to create irregular, natural-looking shores:

### Noise Layers

```typescript
// Large-scale bays and peninsulas (±20% radius variation)
const coastNoise1 = this.noise.fractal2D(
  coastlineNoiseX,
  coastlineNoiseZ,
  3,  // octaves
  0.5,  // persistence
  2.0,  // lacunarity
);

// Medium features (±8% variation)
const coastNoise2 = this.noise.fractal2D(
  coastlineNoiseX * 3,
  coastlineNoiseZ * 3,
  2,
  0.5,
  2.0,
);

// Small coves and points (±2% variation)
const coastNoise3 = this.noise.simplex2D(
  coastlineNoiseX * 8,
  coastlineNoiseZ * 8,
);

// Combined variation (±30% of radius)
const coastlineVariation =
  coastNoise1 * 0.2 + coastNoise2 * 0.08 + coastNoise3 * 0.02;
const effectiveRadius = ISLAND_RADIUS * (1 + coastlineVariation);
```

### Seamless Wrapping

Coastline noise is sampled on a circle to avoid seams at angle wrap:

```typescript
const angle = Math.atan2(worldZ, worldX);

// Sample noise on a circle (radius=2) to avoid seams at 0° = 360°
const coastlineNoiseX = Math.cos(angle) * 2;
const coastlineNoiseZ = Math.sin(angle) * 2;
```

This ensures the coastline wraps smoothly without visible seams.

## Elevation System

### Base Elevation

The island has a base elevation to ensure vegetation spawns correctly:

```typescript
// Vegetation spawns above 11.4m (water 5.4m + 6m buffer)
const baseElevation = 0.42; // Normalized (~12.6m base)
height = height * 0.2 + baseElevation * islandMask;
```

**Terrain Feature Scale**: Existing terrain features are scaled to 20% to prevent extreme peaks while maintaining interesting variation.

### Island Mask

Smooth falloff at island edges:

```typescript
let islandMask = 1.0;
if (distFromCenter > effectiveRadius - ISLAND_FALLOFF) {
  const edgeDist = distFromCenter - (effectiveRadius - ISLAND_FALLOFF);
  const falloffFactor = edgeDist / ISLAND_FALLOFF;
  islandMask = 1.0 - Math.min(1.0, falloffFactor * falloffFactor);
}

// Outside island = deep ocean
if (distFromCenter > effectiveRadius + 50) {
  islandMask = 0;
}
```

## Water Features

### Pond Generation

A pond is placed offset from the island center:

```typescript
const POND_CENTER_X = -80;  // West of spawn
const POND_CENTER_Z = 60;   // South

// Smooth bowl shape for pond
const pondFactor = 1.0 - distFromPond / (POND_RADIUS * 2);
pondDepression = pondFactor * pondFactor * POND_DEPTH;

// Apply pond depression to height
height -= pondDepression;
```

**Pond Position**: Located at (-80, 60) = 100m from origin, well within island radius (220m).

### Water Threshold

```typescript
const WATER_THRESHOLD = 5.4; // Height below which is water
```

Any terrain below 5.4m is considered water and rendered with water shader.

## Shore Height Adjustments

To accommodate elevated island terrain, shore height limits were increased:

```typescript
// Before: shoreMaxHeight = 8.0m
// After:  shoreMaxHeight = 20.0m

// Updated in:
// - ResourceSystem.ts (fishing spot placement)
// - ShoreUtils.ts (default parameter)
```

This allows resources (fishing spots, trees, rocks) to spawn on elevated island terrain.

## Town System Integration

The town system gracefully handles island worlds:

```typescript
if (this.towns.length === 0) {
  // No procedural towns generated - OK if using manifest-defined towns
  Logger.systemWarn(
    "TownSystem",
    "No procedural towns generated - using manifest-defined areas only",
  );
  return;
}
```

Island worlds can use only manifest-defined towns (e.g., Central Haven) without procedural generation.

## Terrain Constants

```typescript
export const CONFIG = {
  MAX_HEIGHT: 30,           // Maximum terrain height in meters
  WATER_THRESHOLD: 5.4,     // Water level
  VEGETATION_BUFFER: 6,     // Buffer above water for vegetation (11.4m total)
  ISLAND_RADIUS: 220,       // Base island radius
  ISLAND_FALLOFF: 60,       // Transition zone width
  POND_RADIUS: 50,          // Pond radius
  POND_DEPTH: 0.55,         // Pond depth (normalized)
  OCEAN_FLOOR: 0.05,        // Ocean floor height (normalized)
  BASE_ELEVATION: 0.42,     // Island base elevation (normalized)
  TERRAIN_FEATURE_SCALE: 0.2, // Scale down terrain features to 20%
};
```

## Height Calculation Flow

```typescript
// 1. Generate base noise (fractal, ridged, cellular)
let height = generateBaseNoise(worldX, worldZ);

// 2. Apply gentle power curve
height = Math.pow(height, 1.1);

// 3. Calculate island mask with coastline variation
const effectiveRadius = ISLAND_RADIUS * (1 + coastlineVariation);
let islandMask = calculateIslandMask(distFromCenter, effectiveRadius);

// 4. Modulate height by island mask
height = height * islandMask;

// 5. Add base elevation
height = height * TERRAIN_FEATURE_SCALE + BASE_ELEVATION * islandMask;

// 6. Apply pond depression
height -= pondDepression;

// 7. Set ocean floor outside island
if (islandMask === 0) {
  height = OCEAN_FLOOR;
}

// 8. Scale to world units
return height * MAX_HEIGHT;
```

## Fishing Spot Placement

Fishing spots are placed along the shoreline using `findShorePoints()`:

```typescript
const fishingSpots = findShorePoints(
  area.bounds,
  terrainSystem.getHeightAt.bind(terrainSystem),
  {
    sampleInterval: 1,        // 1m = 1 tile for tile-accurate detection
    waterThreshold: 5.4,      // TerrainSystem.CONFIG.WATER_THRESHOLD
    shoreMaxHeight: 20.0,     // Higher to accommodate elevated island terrain
    minSpacing: 8,            // Increased spacing to spread spots out
  },
);
```

Algorithm:
1. Sample terrain at 1m intervals within bounds
2. Find tiles where height < 5.4m (water)
3. Check adjacent tiles for shore (5.4m - 20.0m)
4. Apply minimum spacing (8m between spots)
5. Return valid shore positions

## Performance

- **Heightmap Caching**: Terrain heights are calculated once and cached
- **Lazy Evaluation**: Noise functions only called for visible chunks
- **Efficient Noise**: Uses optimized simplex and fractal noise implementations
