# Context Menu System

Hyperscape features OSRS-accurate context menus with colored entity names, proper action ordering, and centralized action dispatching.

<Info>
Context menus are managed by `ContextMenuController` and interaction handlers in `packages/shared/src/systems/client/interaction/`.
</Info>

## Overview

Right-clicking on entities (players, NPCs, items, objects) shows a context menu with available actions. The system uses OSRS-accurate:

- **Color coding**: Orange for items, yellow for NPCs, cyan for objects
- **Action ordering**: Primary actions first, examine last, cancel always last
- **Manifest-driven actions**: Items can define custom actions in their manifest

---

## Color Coding

Context menu entity names use OSRS-accurate colors:

```typescript
// From GameConstants.ts
export const CONTEXT_MENU_COLORS = {
  ITEM: "#ff9040",      // Orange - for items
  NPC: "#ffff00",       // Yellow - for NPCs and mobs
  OBJECT: "#00ffff",    // Cyan - for scenery/objects
  PLAYER: "#ffffff",    // White - for players
};
```

### Examples

- **Items**: "Take <span style="color: #ff9040">Bones</span>"
- **NPCs**: "Talk-to <span style="color: #ffff00">Banker</span>"
- **Objects**: "Chop down <span style="color: #00ffff">Oak</span>"
- **Mobs**: "Attack <span style="color: #ffff00">Goblin</span> (Level: 5)"

## Inventory Context Menus

Inventory items show actions based on their `inventoryActions` manifest field or heuristic detection:

### Manifest-Driven Actions

Items can define explicit actions:

```json
{
  "id": "shrimp",
  "inventoryActions": ["Eat", "Use", "Drop", "Examine"]
}
```

The first action becomes the left-click default.

### Heuristic Detection

If `inventoryActions` is not specified, the system detects actions based on item properties:

| Item Type | Detection | Actions |
|-----------|-----------|---------|
| Food | `type: "consumable"` + `healAmount > 0` | Eat, Use, Drop, Examine |
| Potions | `type: "consumable"` + `id.includes("potion")` | Drink, Use, Drop, Examine |
| Weapons | `equipSlot: "weapon"` or `equipSlot: "2h"` | Wield, Use, Drop, Examine |
| Armor | `equipable: true` + not weapon/shield | Wear, Use, Drop, Examine |
| Shields | `equipSlot: "shield"` | Wield, Use, Drop, Examine |
| Bones | `id === "bones"` or `id.endsWith("_bones")` | Bury, Use, Drop, Examine |
| Noted Items | `isNoted: true` or `id.endsWith("_noted")` | Use, Drop, Examine |

### Action Handlers

The `InventoryActionDispatcher` provides centralized handling for all inventory actions:

```typescript
// From packages/client/src/game/systems/InventoryActionDispatcher.ts
export function dispatchInventoryAction(
  action: string,
  ctx: InventoryActionContext
): ActionResult {
  // Handles: eat, drink, bury, wield, wear, drop, examine, use, cancel
}
```

Supported actions:

- **eat**: Sends `useItem` network message → server validates eat delay → consumes food → heals HP
- **drink**: Emits `ITEM_ACTION_SELECTED` event for potion effects
- **bury**: Sends `buryBones` network message
- **wield**: Sends `equipItem` network message (weapons/shields)
- **wear**: Sends `equipItem` network message (armor)
- **drop**: Calls `world.network.dropItem()`
- **examine**: Shows examine text in chat and toast
- **use**: Enters targeting mode for item-on-item/item-on-object interactions
- **cancel**: No-op, menu already closed

<Info>
**Food Consumption**: The eat action is server-authoritative with 3-tick (1.8s) eat delay and combat attack delay integration. See [Inventory System](/wiki/game-systems/inventory#item-consumption) for details.
</Info>

## Entity Context Menus

Different entity types have different context menu formats:

### Items (Ground)

Format: "Take <span style="color: #ff9040">ItemName</span>"

```typescript
// From ItemInteractionHandler.ts
{
  id: "pickup_item123",
  label: "Take Bones",
  styledLabel: [
    { text: "Take " },
    { text: "Bones", color: CONTEXT_MENU_COLORS.ITEM }
  ],
  enabled: true,
  priority: 1
}
```

### NPCs

Format: "Talk-to <span style="color: #ffff00">NPCName</span>"

```typescript
// From NPCInteractionHandler.ts
{
  id: "talk",
  label: "Talk-to Banker",
  styledLabel: [
    { text: "Talk-to " },
    { text: "Banker", color: CONTEXT_MENU_COLORS.NPC }
  ],
  enabled: true,
  priority: 1
}
```

Bankers also show:
- "Bank <span style="color: #ffff00">Banker</span>"
- "Collect <span style="color: #ffff00">Banker</span>" (for Grand Exchange)

### Mobs

Format: "Attack <span style="color: #ffff00">MobName</span> (Level: X)"

```typescript
// From MobInteractionHandler.ts
{
  id: "attack",
  label: "Attack Goblin (Level: 5)",
  styledLabel: [
    { text: "Attack " },
    { text: "Goblin", color: CONTEXT_MENU_COLORS.NPC },
    { text: " (Level: " },
    { text: "5", color: levelColor },  // Color based on player vs mob level
    { text: ")" }
  ],
  enabled: true,
  priority: 1
}
```

### Resources

Format: "Chop down <span style="color: #00ffff">TreeName</span>"

Trees strip the "Tree" suffix (Oak Tree → Oak), rocks use lowercase plural (Copper Rock → Copper rocks):

```typescript
// From ResourceInteractionHandler.ts
{
  id: "chop",
  label: "Chop down Oak",
  styledLabel: [
    { text: "Chop down " },
    { text: "Oak", color: CONTEXT_MENU_COLORS.OBJECT }
  ],
  enabled: true,
  priority: 1
}
```

Mining: "Mine <span style="color: #00ffff">Copper rocks</span>"

### Stations

Format: "Smith <span style="color: #00ffff">Anvil</span>"

```typescript
// From SmithingSourceInteractionHandler.ts
```

## Action Priority

Actions are sorted by priority (lower = higher in menu):

| Priority | Action Type |
|----------|-------------|
| 1 | Primary action (Attack, Take, Chop, etc.) |
| 2-10 | Secondary actions (Bank, Trade, etc.) |
| 50 | Walk here |
| 100+ | Examine |
| Last | Cancel (always) |

---

## Targeting Mode

The "Use" action enters targeting mode for item-on-item or item-on-object interactions:

1. Right-click item → Select "Use"
2. Cursor changes to crosshair
3. Click valid target (highlighted in gold)
4. Action executes (e.g., tinderbox on logs → firemaking)

Invalid targets show: "Nothing interesting happens."

## Implementation Details

### Interaction Handlers

Each entity type has a dedicated handler:

| Handler | Entity Types | File |
|---------|--------------|------|
| `ItemInteractionHandler` | Ground items | `handlers/ItemInteractionHandler.ts` |
| `NPCInteractionHandler` | NPCs (bankers, shopkeepers) | `handlers/NPCInteractionHandler.ts` |
| `MobInteractionHandler` | Hostile mobs | `handlers/MobInteractionHandler.ts` |
| `PlayerInteractionHandler` | Other players | `handlers/PlayerInteractionHandler.ts` |
| `ResourceInteractionHandler` | Trees, rocks, fishing spots | `handlers/ResourceInteractionHandler.ts` |
| `BankInteractionHandler` | Bank booths/chests | `handlers/BankInteractionHandler.ts` |
| `CookingSourceInteractionHandler` | Fires, ranges | `handlers/CookingSourceInteractionHandler.ts` |
| `SmeltingSourceInteractionHandler` | Furnaces | `handlers/SmeltingSourceInteractionHandler.ts` |
| `SmithingSourceInteractionHandler` | Anvils | `handlers/SmithingSourceInteractionHandler.ts` |
| `CorpseInteractionHandler` | Gravestones, corpses | `handlers/CorpseInteractionHandler.ts` |

### InteractionRouter

The `InteractionRouter` dispatches raycast targets to the appropriate handler:

```typescript
// From InteractionRouter.ts
export class InteractionRouter {
  private handlers = new Map<string, BaseInteractionHandler>();

  handleLeftClick(target: RaycastTarget): void {
    const handler = this.getHandlerForTarget(target);
    handler?.handleLeftClick(target);
  }

  handleRightClick(target: RaycastTarget): ContextMenuAction[] {
    const handler = this.getHandlerForTarget(target);
    return handler?.getContextMenuActions(target) || [];
  }
}
```

## Item Helpers

The system provides type detection helpers for inventory actions:

```typescript
// From packages/shared/src/utils/item-helpers.ts
import { isFood, isPotion, isBone, usesWield, usesWear, getPrimaryAction } from '@hyperscape/shared';

// Detect item types
const canEat = isFood(item);           // true for food items
const canDrink = isPotion(item);       // true for potions
const canBury = isBone(item);          // true for bones
const shouldWield = usesWield(item);   // true for weapons/shields
const shouldWear = usesWear(item);     // true for armor

// Get primary action (for left-click)
const action = getPrimaryAction(item, isNoted);
// Returns: "eat" | "drink" | "bury" | "wield" | "wear" | "use"
```

## Adding Custom Actions

To add a new inventory action:

1. **Define in manifest**:
```json
{
  "id": "prayer_book",
  "inventoryActions": ["Read", "Use", "Drop", "Examine"]
}
```

2. **Add handler to InventoryActionDispatcher**:
```typescript
case "read":
  world.emit(EventType.ITEM_ACTION_SELECTED, {
    playerId: localPlayer.id,
    actionId: "read",
    itemId,
    slot,
  });
  return { success: true };
```

3. **Handle event in appropriate system**:
```typescript
world.on(EventType.ITEM_ACTION_SELECTED, (payload) => {
  if (payload.actionId === "read") {
    // Handle reading prayer book
  }
});
```
