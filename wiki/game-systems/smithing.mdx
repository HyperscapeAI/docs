# Smithing System

The Smithing skill allows players to smelt ores into metal bars at furnaces and smith bars into weapons, armor, and tools at anvils. This is a two-stage artisan skill following OSRS mechanics.

<Info>
Smithing is managed by `SmeltingSystem` and `SmithingSystem` in `packages/shared/src/systems/shared/interaction/`.
</Info>

## Overview

Smithing has two main activities:

1. **Smelting** - Convert ores into bars at furnaces
2. **Smithing** - Convert bars into equipment at anvils

Both activities use tick-based processing (4 ticks per action = 2.4 seconds at 600ms/tick).

---

## Smelting

### How to Smelt

1. Gather ores through Mining or purchase from shops
2. Find a furnace (blue placeholder or 3D model)
3. Click the furnace to open the smelting interface
4. Select a bar type and quantity (1, 5, 10, All, or X for custom)
5. Wait for smelting to complete (4 ticks per bar)

### Smelting Requirements

| Bar | Level | Primary Ore | Secondary Ore | Coal | Success Rate | XP |
|-----|-------|-------------|---------------|------|--------------|-----|
| Bronze | 1 | Copper | Tin | 0 | 100% | 6.25 |
| Iron | 15 | Iron | - | 0 | 50% | 12.5 |
| Steel | 30 | Iron | - | 2 | 100% | 17.5 |
| Mithril | 50 | Mithril | - | 4 | 100% | 30 |
| Adamant | 70 | Adamantite | - | 6 | 100% | 37.5 |
| Rune | 85 | Runite | - | 8 | 100% | 50 |

<Warning>
**Iron Smelting**: Iron ore has a 50% success rate when smelting. Failed attempts consume the ore with no bar produced.
</Warning>

### Smelting Interface

The smelting UI shows:
- Available bars based on your inventory
- Level requirements for each bar
- Ore requirements (primary, secondary, coal)
- Quantity selection buttons

**Make X Memory**: The interface remembers your last custom quantity (OSRS feature).

## Smithing

### How to Smith

1. Smelt bars at a furnace
2. Ensure you have a hammer in your inventory
3. Find an anvil (blue placeholder or 3D model)
4. Click the anvil to open the smithing interface
5. Select an item and quantity
6. Wait for smithing to complete (4 ticks per item)

### Smithing Requirements

All smithing requires:
- A hammer in your inventory
- Sufficient bars for the item
- Required Smithing level

## Manifest-Driven Architecture

Smithing uses a **manifest-driven architecture** where all recipes are defined in JSON files rather than hardcoded.

### Recipe Manifests

Located in `packages/server/world/assets/manifests/recipes/`:

- `smelting.json` - Smelting recipes (ores → bars)
- `smithing.json` - Smithing recipes (bars → equipment)

### Smelting Manifest Structure

```json
{
  "recipes": [
    {
      "output": "bronze_bar",
      "inputs": [
        { "item": "copper_ore", "amount": 1 },
        { "item": "tin_ore", "amount": 1 }
      ],
      "level": 1,
      "xp": 6.25,
      "ticks": 4,
      "successRate": 1.0
    }
  ]
}
```

### Smithing Manifest Structure

```json
{
  "recipes": [
    {
      "output": "bronze_sword",
      "bar": "bronze_bar",
      "barsRequired": 1,
      "level": 4,
      "xp": 12.5,
      "ticks": 4,
      "category": "weapons"
    }
  ]
}
```

## Data Providers

### ProcessingDataProvider

Provides runtime access to smelting and smithing recipes:

```typescript
import { processingDataProvider } from '@hyperscape/shared';

// Check if item is smeltable
const canSmelt = processingDataProvider.isSmeltableBar('bronze_bar');

// Get smelting data
const smeltingData = processingDataProvider.getSmeltingData('bronze_bar');
// Returns: { primaryOre, secondaryOre, coalRequired, levelRequired, xp, ticks }

// Get smithing recipe
const recipe = processingDataProvider.getSmithingRecipe('bronze_sword');
// Returns: { barType, barsRequired, levelRequired, xp, category, ticks }

// Get all recipes for a bar type
const recipes = processingDataProvider.getSmithingRecipesForBar('bronze_bar');
```

### TierDataProvider

Provides tier-based level requirements for equipment:

```typescript
import { TierDataProvider } from '@hyperscape/shared';

// Get requirements for a tiered item
const requirements = TierDataProvider.getRequirements({
  id: 'steel_sword',
  type: 'weapon',
  tier: 'steel',
  equipSlot: 'weapon',
  attackType: 'MELEE'
});
// Returns: { attack: 5 }
```

### StationDataProvider

Provides 3D model paths and configuration for world stations:

```typescript
import { stationDataProvider } from '@hyperscape/shared';

// Get station data
const anvilData = stationDataProvider.getStationData('anvil');
// Returns: { model, modelScale, modelYOffset, examine }

// Get model path
const modelPath = stationDataProvider.getModelPath('furnace');
// Returns: "asset://models/furnace/furnace.glb"
```

## Tick-Based Processing

Both smelting and smithing use **tick-based processing** for OSRS-accurate timing:

- **Default**: 4 ticks per action (2.4 seconds at 600ms/tick)
- **Configurable**: Can be overridden in recipe manifests via `ticks` field
- **Server-authoritative**: All timing is server-side to prevent cheating

### Processing Flow

1. Player selects item and quantity from UI
2. Client sends request to server
3. Server validates inventory, level, and station proximity
4. Server starts tick-based processing session
5. Every 4 ticks, one item is processed
6. XP is granted and items are added/removed from inventory
7. Session continues until quantity is complete or player moves

## Rate Limiting

Both smelting and smithing have rate limiting to prevent spam:

- **Cooldown**: 500ms between requests per player
- **Validation**: Input validation for item IDs, quantities, and slot bounds
- **Bounds**: Quantity clamped to 1-10,000 range

From `SmithingConstants.ts`:
```typescript
export const SMITHING_CONSTANTS = {
  MAX_QUANTITY: 10000,
  MIN_QUANTITY: 1,
  MAX_ITEM_ID_LENGTH: 64,
  TICK_DURATION_MS: 600,
  DEFAULT_SMELTING_TICKS: 4,
  DEFAULT_SMITHING_TICKS: 4,
};
```

## Type Guards and Validation

The smithing system includes type guards for safe entity access:

```typescript
import { hasSkills, getSmithingLevelSafe } from '@hyperscape/shared';

// Check if entity has skills
if (hasSkills(entity)) {
  const level = entity.skills?.smithing?.level ?? 1;
}

// Safe level getter with default
const level = getSmithingLevelSafe(entity, 1);
```
