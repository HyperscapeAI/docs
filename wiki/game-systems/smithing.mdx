# Smithing System

The Smithing skill allows players to smelt ores into metal bars at furnaces and smith bars into weapons, armor, and tools at anvils. This is a two-stage artisan skill following OSRS mechanics.

<Info>
Smithing is managed by `SmeltingSystem` and `SmithingSystem` in `packages/shared/src/systems/shared/interaction/`.
</Info>

---

## Overview

Smithing consists of two distinct activities:

1. **Smelting** - Convert ores into metal bars at a furnace
2. **Smithing** - Convert metal bars into equipment at an anvil

Both activities grant Smithing XP and follow OSRS-accurate mechanics.

---

## Stage 1: Smelting

### Requirements

- Ores in inventory (copper, tin, iron, coal, mithril, adamantite, runite)
- Access to a furnace (permanent world object)

### How to Smelt

1. Click on a furnace
2. Select the bar type from the interface
3. Choose quantity:
   - **1** - Smelt 1 bar
   - **5** - Smelt 5 bars
   - **10** - Smelt 10 bars
   - **All** - Smelt 28 bars (full inventory)
   - **X** - Enter custom amount
4. Wait for smelting to complete

### Smelting Recipes

| Bar | Level | Ores Required | XP | Success Rate | Ticks |
|-----|-------|---------------|-----|--------------|-------|
| Bronze | 1 | 1 Copper + 1 Tin | 6.25 | 100% | 4 |
| Iron | 15 | 1 Iron Ore | 12.5 | 50% | 4 |
| Steel | 30 | 1 Iron Ore + 2 Coal | 17.5 | 100% | 4 |
| Mithril | 50 | 1 Mithril Ore + 4 Coal | 30 | 100% | 4 |
| Adamant | 70 | 1 Adamantite Ore + 6 Coal | 37.5 | 100% | 4 |
| Rune | 85 | 1 Runite Ore + 8 Coal | 50 | 100% | 4 |

<Warning>
**Iron Ore Failure**: Iron ore has a 50% chance to fail when smelting, consuming the ore without producing a bar. This matches OSRS mechanics and makes iron bars less efficient than other metals.
</Warning>

### Smelting Timing

- **4 ticks per bar** (2.4 seconds)
- Actions are queued and processed on tick boundaries
- Multiple bars are smelted sequentially

## Stage 2: Smithing

### Requirements

- **Hammer** in inventory (not consumed)
- Metal bars in inventory
- Access to an anvil (permanent world object)

### How to Smith

1. Click on an anvil
2. Select the item to smith from the interface
3. Choose quantity (1, 5, 10, All, or X)
4. Wait for smithing to complete

### Smithing Categories

Items are organized by category in the smithing interface:

- **Weapons** - Swords, scimitars, daggers, axes, maces, warhammers
- **Armor** - Helmets, platebodies, platelegs, shields, boots, gauntlets
- **Tools** - Pickaxes, hatchets
- **Misc** - Nails, arrowtips, dart tips, knives

## Make X Memory

The smithing interface remembers your last custom quantity:

1. Select an item to smith
2. Click **X** to enter custom quantity
3. Enter amount (e.g., 50)
4. Next time you click **X**, it defaults to 50

This feature:
- Persists in browser localStorage
- Works separately for smelting and smithing
- Matches OSRS's "Make X" memory behavior

## System Architecture

### SmeltingSystem

**Location**: `packages/shared/src/systems/shared/interaction/SmeltingSystem.ts`

**Responsibilities:**
- Handle furnace interactions
- Validate ore availability and level requirements
- Process smelting actions on tick boundaries
- Apply success/failure rates (iron ore)
- Grant Smithing XP
- Manage active smelting sessions

**Key Methods:**
```typescript
// Check if player is currently smelting
isPlayerSmelting(playerId: string): boolean

// Internal: Handle furnace click
private handleFurnaceInteract(data: { playerId, furnaceId }): void

// Internal: Start smelting session
private startSmelting(data: { playerId, barItemId, furnaceId, quantity }): void

// Internal: Complete single smelt action
private completeSmelt(playerId: string): void
```

### SmithingSystem

**Location**: `packages/shared/src/systems/shared/interaction/SmithingSystem.ts`

**Responsibilities:**
- Handle anvil interactions
- Validate hammer and bar availability
- Process smithing actions on tick boundaries
- Grant Smithing XP
- Manage active smithing sessions

**Key Methods:**
```typescript
// Check if player is currently smithing
isPlayerSmithing(playerId: string): boolean

// Internal: Handle anvil click
private handleAnvilInteract(data: { playerId, anvilId }): void

// Internal: Start smithing session
private startSmithing(data: { playerId, recipeId, anvilId, quantity }): void

// Internal: Complete single smith action
private completeSmith(playerId: string): void
```

## Events

### Smelting Events

| Event | Payload | Description |
|-------|---------|-------------|
| `SMELTING_INTERACT` | `{ playerId, furnaceId, position }` | Player clicked furnace |
| `SMELTING_INTERFACE_OPEN` | `{ playerId, furnaceId, availableBars }` | Show smelting UI |
| `PROCESSING_SMELTING_REQUEST` | `{ playerId, barItemId, furnaceId, quantity }` | Player selected bar to smelt |
| `SMELTING_START` | `{ playerId, barItemId, furnaceId }` | Smelting session started |
| `SMELTING_SUCCESS` | `{ playerId, barItemId, xpGained }` | Bar smelted successfully |
| `SMELTING_FAILURE` | `{ playerId, barItemId }` | Smelting failed (iron ore) |
| `SMELTING_COMPLETE` | `{ playerId, barItemId, totalSmelted, totalFailed, totalXp }` | Session finished |

### Smithing Events

| Event | Payload | Description |
|-------|---------|-------------|
| `SMITHING_INTERACT` | `{ playerId, anvilId, position }` | Player clicked anvil |
| `SMITHING_INTERFACE_OPEN` | `{ playerId, anvilId, availableRecipes }` | Show smithing UI |
| `PROCESSING_SMITHING_REQUEST` | `{ playerId, recipeId, anvilId, quantity }` | Player selected item to smith |
| `SMITHING_START` | `{ playerId, recipeId, anvilId }` | Smithing session started |
| `SMITHING_COMPLETE` | `{ playerId, recipeId, totalSmithed, totalXp }` | Session finished |

## Rate Limiting

Both smelting and smithing requests are rate-limited to prevent spam:

**Location**: `packages/server/src/systems/ServerNetwork/index.ts`

```typescript
// Rate limiting check before processing
if (!this.canProcessRequest(player.id)) {
  return; // Silently reject spam requests
}
```

**Limits:**
- 1 request per 100ms per player
- Prevents request flooding
- Applies to both smelting and smithing

## Input Validation

All smithing inputs are validated server-side:

### Type Validation

```typescript
// Validate string types
if (typeof payload.barItemId !== "string" || 
    typeof payload.furnaceId !== "string") {
  return; // Reject invalid types
}
```

### Length Validation

```typescript
// Prevent memory abuse
if (payload.barItemId.length > 64 || 
    payload.furnaceId.length > 64) {
  return; // Reject oversized strings
}
```

### Quantity Validation

```typescript
// Clamp to safe bounds
const quantity = typeof payload.quantity === "number" && 
                 Number.isFinite(payload.quantity)
  ? Math.floor(Math.max(1, Math.min(payload.quantity, 10000)))
  : 1;
```

  it("filters by smithing level", () => {
    const inventory = [{ itemId: "bronze_bar", quantity: 10 }];
    const level1 = provider.getSmithableItemsFromInventory(inventory, 1);
    const level99 = provider.getSmithableItemsFromInventory(inventory, 99);

    expect(withFive.length).toBeGreaterThanOrEqual(withOne.length);
  });
});

## Performance Optimizations

### Pre-Allocated Buffers

ProcessingDataProvider uses pre-allocated buffers to avoid GC pressure:

```typescript
// Pre-allocated Map for inventory counting
private readonly inventoryCountBuffer = new Map<string, number>();

// Reused across multiple calls
private buildInventoryCounts(inventory): Map<string, number> {
  this.inventoryCountBuffer.clear();
  // ... populate buffer
  return this.inventoryCountBuffer;
}
```

### Memory Management

- Player skills cached in `Map<string, Record<string, SkillData>>`
- Cache cleared on player disconnect
- Prevents memory leaks from orphaned player data
