# UI System

Hyperscape's UI system provides a flexible, responsive interface with drag-and-drop, theming, and window management.

<Info>
All UI code is in `packages/client/src/ui/` (consolidated from the removed `hs-kit` package in January 2026).
</Info>

## Window System

### Window Component

```typescript
import { Window } from '@/ui';

<Window
  id="inventory"
  title="Inventory"
  defaultPosition={{ x: 100, y: 100 }}
  defaultSize={{ width: 400, height: 500 }}
  anchor="bottom-right"
  resizable={true}
  closable={true}
  onClose={() => console.log('Window closed')}
>
  {/* Window content */}
</Window>
```

### Window Anchors

Windows use anchor-based positioning for responsive scaling:

```typescript
// From packages/client/src/ui/types.ts
export type WindowAnchor =
  | "top-left" | "top-center" | "top-right"
  | "center-left" | "center" | "center-right"
  | "bottom-left" | "bottom-center" | "bottom-right";
```

**How anchors work:**
- Windows store **offset from anchor** instead of absolute position
- When viewport resizes, windows maintain their anchor relationship
- Prevents clustering when switching between mobile and desktop

**Default anchors:**
- Chat, Skills: `bottom-left`
- Minimap: `top-right`
- Inventory, Menubar: `bottom-right`
- Action bar: `bottom-center`

### Window Store

```typescript
import { useWindowStore } from '@/ui';

// Get window state
const window = useWindowStore((s) => s.windows.get('inventory'));

// Update window position
useWindowStore.getState().updateWindow('inventory', {
  position: { x: 200, y: 200 },
});

// Close window
useWindowStore.getState().closeWindow('inventory');
```

## Drag-and-Drop System

Hyperscape uses `@dnd-kit` for drag-and-drop functionality:

### useDrag Hook

```typescript
import { useDrag } from '@/ui/core/drag';

const { attributes, listeners, setNodeRef, isDragging } = useDrag({
  id: 'item-bronze-sword',
  data: {
    type: 'inventory',
    slot: 5,
    itemId: 'bronze_sword',
    quantity: 1,
  },
});

<div ref={setNodeRef} {...listeners} {...attributes}>
  {/* Draggable content */}
</div>
```

### useDrop Hook

```typescript
import { useDrop } from '@/ui/core/drag';

const { setNodeRef, isOver } = useDrop({
  id: 'equipment-weapon',
  accept: ['inventory'],
  onDrop: (item) => {
    console.log('Dropped:', item);
    // Handle drop
  },
});

<div ref={setNodeRef} style={{ background: isOver ? 'green' : 'transparent' }}>
  {/* Drop zone */}
</div>
```

### Drag Context

```typescript
import { DragContext } from '@/ui/core/drag';

<DragContext>
  {/* Draggable and droppable components */}
</DragContext>
```

**Features:**
- Keyboard accessibility (Space/Enter to pick up, arrow keys to move)
- Pointer events (mouse and touch)
- Custom collision detection
- Drag modifiers (snap to grid, restrict axis)
- Visual feedback (hover states, drop previews)

## Accessibility

### Keyboard Navigation

All interactive elements support keyboard navigation:

- **Tab**: Focus next element
- **Shift+Tab**: Focus previous element
- **Enter/Space**: Activate button or drag item
- **Escape**: Close modal or cancel drag
- **Arrow keys**: Move dragged item (when using keyboard drag)

### Screen Reader Support

```typescript
// Example: Accessible button
<button
  role="button"
  tabIndex={0}
  aria-label="Close window"
  onClick={handleClose}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      e.preventDefault();
      handleClose();
    }
  }}
>
  ×
</button>
```

## Performance Optimizations

### Memoization

Components are memoized to prevent unnecessary re-renders:

```typescript
import { memo } from 'react';

export const ChatBox = memo(function ChatBox({ /* props */ }) {
  // Component implementation
});
```

### Consolidated Refs

The `useDrop` hook consolidates multiple refs into a single object:

```typescript
// Before: 6 separate refs
const onDropRef = useRef(onDrop);
const acceptRef = useRef(accept);
// ... 4 more refs

// After: Single savedStateRef
const savedStateRef = useRef({
  onDrop,
  accept,
  disabled,
  id,
  data,
  collisionDetection,
});
```

### Effect Consolidation

Multiple effects combined for better performance:

```typescript
// Before: 3 separate effects
useEffect(() => { /* save onDrop */ }, [onDrop]);
useEffect(() => { /* save accept */ }, [accept]);
useEffect(() => { /* register drop zone */ }, [id]);

// After: 2 combined effects
useEffect(() => {
  // Save all callbacks
  savedStateRef.current = { onDrop, accept, disabled, id, data, collisionDetection };
}, [onDrop, accept, disabled, id, data, collisionDetection]);

useEffect(() => {
  // Register drop zone
}, [id]);
```

## Migration from hs-kit

The `hs-kit` package was removed in January 2026. All imports should be updated:

```typescript
// Before (hs-kit)
import { Window, useThemeStore, useDrag } from 'hs-kit';

// After (consolidated UI)
import { Window, useThemeStore } from '@/ui';
import { useDrag } from '@/ui/core/drag';
```

**Import alias:**
```typescript
// tsconfig.json
{
  "compilerOptions": {
    "paths": {
      "@/ui": ["./src/ui"],
      "@/ui/*": ["./src/ui/*"]
    }
  }
}
```
