## Overview

The Hyperscape UI system provides a flexible, responsive interface with draggable windows, tab management, and anchor-based positioning. The architecture separates reusable UI primitives from game-specific components.

<Info>
  UI code lives in `packages/client/src/ui/` (design system) and `packages/client/src/game/` (game-specific).
</Info>

## Architecture

### Design Principles

1. **Separation of Concerns**: UI primitives (`ui/`) vs game logic (`game/`)
2. **Anchor-Based Positioning**: Windows maintain position relative to viewport anchors
3. **Responsive Design**: Automatic repositioning on viewport resize
4. **Drag-and-Drop**: Unified system for items, windows, and tabs
5. **State Management**: Zustand stores for UI state

### Responsive Behavior

**On Viewport Resize:**
1. Calculate scale factor (new viewport / saved viewport)
2. Reposition windows using anchor + offset
3. Maintain edge alignment for edge-positioned windows
4. Clamp to viewport bounds

**Mobile-to-Desktop Transitions:**
1. Detect layout mode change (mobile → desktop)
2. Use default layout positions instead of scaling
3. Apply stacking offsets for windows sharing same anchor
4. Prevents window clustering from meaningless mobile positions

### useDrop Hook

```typescript
// From packages/client/src/ui/core/drag/useDrop.ts
export function useDrop({ id, accept, onDrop }: UseDropProps) {
  const { setNodeRef, isOver } = useDroppable({
    id,
    data: { accept },
  });
  
  // Fixed race condition: save drag state in refs
  const savedDragItemRef = useRef<DragItem | null>(null);
  const savedOverTargetsRef = useRef<string[]>([]);
  
  useEffect(() => {
    if (isDragging) {
      savedDragItemRef.current = dragItem;
      savedOverTargetsRef.current = overTargets;
    }
  }, [isDragging, dragItem, overTargets]);
  
  // Use saved refs in drop effect
  useEffect(() => {
    if (!isDragging && savedDragItemRef.current) {
      const wasOver = savedOverTargetsRef.current.includes(id);
      if (wasOver && onDrop) {
        onDrop(savedDragItemRef.current);
      }
    }
  }, [isDragging]);
  
  return {
    dropRef: setNodeRef,
    isOver,
  };
}
```

**Key Fixes:**
- Race condition resolved: drag state saved in refs before clearing
- Dynamic disabled registration: drop zones re-register when disabled changes
- Proper event timing: drop fires before state clears

### Tab Combining

Drag windows onto each other to combine into tabs:

1. Press **L** to enter edit mode
2. Drag a window by its title bar
3. Drop on target window (entire window is drop zone)
4. Windows combine into tabbed interface
5. Tab preview shows combined result before drop

**Drop Zones:**
- `tabbar-{windowId}`: Multi-tab windows
- `window-header-drop-{windowId}`: Single-tab windows
- `window-content-drop-{windowId}`: Window body

## Edit Mode

### Activation

Press **L** key to toggle edit mode:

```typescript
// From packages/client/src/ui/core/edit/useEditMode.ts
export function useEditMode() {
  const isEditMode = useEditStore((state) => state.isEditMode);
  const toggleEditMode = useEditStore((state) => state.toggle);
  
  useEffect(() => {
    const handleKeyPress = (e: KeyboardEvent) => {
      if (e.key === "l" || e.key === "L") {
        toggleEditMode();
      }
    };
    
    window.addEventListener("keydown", handleKeyPress);
    return () => window.removeEventListener("keydown", handleKeyPress);
  }, []);
  
  return { isEditMode, toggleEditMode };
}
```

### Edit Mode Features

When edit mode is active:
- Windows become draggable
- Windows can be resized
- Windows can be combined into tabs
- Alignment guides appear
- Grid snapping enabled (optional)

## Responsive Design

### Breakpoints

```typescript
// From packages/client/src/ui/core/responsive/useBreakpoint.ts
export const BREAKPOINTS = {
  mobile: 768,
  tablet: 1024,
  desktop: 1280,
  wide: 1920,
} as const;

export function useBreakpoint() {
  const [breakpoint, setBreakpoint] = useState<Breakpoint>("desktop");
  
  useEffect(() => {
    const updateBreakpoint = () => {
      const width = window.innerWidth;
      if (width < BREAKPOINTS.mobile) setBreakpoint("mobile");
      else if (width < BREAKPOINTS.tablet) setBreakpoint("tablet");
      else if (width < BREAKPOINTS.desktop) setBreakpoint("desktop");
      else setBreakpoint("wide");
    };
    
    window.addEventListener("resize", updateBreakpoint);
    updateBreakpoint();
    
    return () => window.removeEventListener("resize", updateBreakpoint);
  }, []);
  
  return breakpoint;
}
```

### Mobile Layout

## Accessibility

### Keyboard Navigation

All interactive elements support keyboard:

```typescript
// From packages/client/src/ui/core/drag/accessibility.ts
export function makeAccessible(element: HTMLElement, handlers: {
  onActivate?: () => void;
  onDragStart?: () => void;
  onDragEnd?: () => void;
}) {
  element.setAttribute("role", "button");
  element.setAttribute("tabIndex", "0");
  
  element.addEventListener("keydown", (e) => {
    if (e.key === "Enter" || e.key === " ") {
      e.preventDefault();
      handlers.onActivate?.();
    }
  });
}
```

### Screen Reader Support

- ARIA labels on all interactive elements
- Role attributes for semantic meaning
- Focus management for modals and panels
- Skip links for navigation

### Virtual Scrolling

```typescript
// From packages/client/src/ui/core/virtual/useVirtualList.ts
export function useVirtualList<T>({
  items,
  itemHeight,
  containerHeight,
}: VirtualListProps<T>) {
  const [scrollTop, setScrollTop] = useState(0);
  
  const startIndex = Math.floor(scrollTop / itemHeight);
  const endIndex = Math.ceil((scrollTop + containerHeight) / itemHeight);
  
  const visibleItems = items.slice(startIndex, endIndex);
  
  return { visibleItems, startIndex, totalHeight: items.length * itemHeight };
}
```

### Render Optimization

- `useMemo` for expensive calculations
- `useCallback` for event handlers
- Hoisted styles to prevent re-creation
- Ref-based event dispatch to avoid state setter closures
