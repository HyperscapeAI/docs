## Overview

The DuelCombatAI system provides autonomous combat control for AI agents during arena duels. Introduced in the streaming duel system, it handles tick-based combat decisions, LLM strategy planning, and trash talk generation.

## DuelCombatAI Class

Located in `packages/server/src/arena/DuelCombatAI.ts`, this class takes over agent behavior during combat:

```typescript
import { DuelCombatAI } from './DuelCombatAI';

const combatAI = new DuelCombatAI(
  service,           // EmbeddedHyperscapeService
  opponentId,        // Target character ID
  {
    useLlmTactics: true,      // Enable LLM strategy planning
    healThresholdPct: 40      // HP% to start healing
  },
  runtime,           // AgentRuntime for LLM calls (optional)
  sendChatMessage    // Callback for trash talk (optional)
);

// Start combat AI
combatAI.start();

// Tick combat AI (called by StreamingDuelScheduler)
await combatAI.externalTick();

// Stop combat AI
combatAI.stop();
```

## Combat Decision Priority

The combat AI uses a priority-based decision system:

1. **Heal** - If HP below threshold (default 40%)
2. **Buff** - Activate prayers/buffs if available
3. **Strategy** - Execute LLM-generated tactics
4. **Attack** - Default attack behavior

## Combat Phases

The AI adapts behavior based on fight progression:

### Opening Phase (0-20% fight duration)

- Establish positioning
- Activate buffs/prayers
- Initial strategy execution

### Trading Phase (20-60% fight duration)

- Execute main combat strategy
- Monitor HP thresholds
- Adjust tactics based on opponent behavior

### Finishing Phase (60-90% fight duration)

- Aggressive tactics if winning
- Defensive tactics if losing
- Prepare for final push

### Desperate Phase (90-100% fight duration)

- All-in attacks if losing
- Secure victory if winning
- Maximum healing priority

## Trash Talk System

AI agents taunt opponents during combat with LLM-generated or scripted trash talk (added in commit 8ff3ad3):

### Health Threshold Taunts

Triggered when HP crosses specific thresholds:

| Threshold | Own HP Low | Opponent HP Low |
|-----------|------------|-----------------|
| 75% | "Not even close!" | "GG soon" |
| 50% | "I've had worse" | "You're done!" |
| 25% | "Is that all?" | "Sit down" |
| 10% | "Still standing!" | "It's over!" |

**Implementation:**

```typescript
// From packages/server/src/arena/DuelCombatAI.ts

private checkHealthMilestones(
  myHp: number,
  myMaxHp: number,
  oppHp: number,
  oppMaxHp: number
): void {
  const myPct = (myHp / myMaxHp) * 100;
  const oppPct = (oppHp / oppMaxHp) * 100;

  // Check own HP thresholds
  for (const threshold of [75, 50, 25, 10]) {
    if (
      this.prevMyHpPct > threshold &&
      myPct <= threshold &&
      !this.firedOwnThresholds.has(threshold)
    ) {
      this.firedOwnThresholds.add(threshold);
      this.fireTrashTalk('own_low', myPct, oppPct);
      break;
    }
  }

  // Check opponent HP thresholds
  for (const threshold of [75, 50, 25, 10]) {
    if (
      this.prevOppHpPct > threshold &&
      oppPct <= threshold &&
      !this.firedOpponentThresholds.has(threshold)
    ) {
      this.firedOpponentThresholds.add(threshold);
      this.fireTrashTalk('opponent_low', myPct, oppPct);
      break;
    }
  }

  this.prevMyHpPct = myPct;
  this.prevOppHpPct = oppPct;
}
```

### LLM-Generated Taunts

Uses agent character bio and communication style for personalized trash talk:

```typescript
private async generateLlmTrashTalk(
  situation: 'own_low' | 'opponent_low' | 'ambient',
  myHpPct: number,
  oppHpPct: number
): Promise<string | null> {
  if (!this.runtime) return null;

  const character = this.runtime.character;
  const bioSnippet = character.bio?.[0]?.substring(0, 200) || '';
  const styleHints = character.style?.all?.slice(0, 3) || [];

  const prompt = `
You are ${character.name}. ${bioSnippet}

Communication style: ${styleHints.join(', ')}

You're in a duel. Your HP: ${myHpPct.toFixed(0)}%, Opponent HP: ${oppHpPct.toFixed(0)}%

Situation: ${situation}

Generate a SHORT trash talk message (under 40 characters). Be in-character.
`;

  try {
    const response = await Promise.race([
      this.runtime.completion({
        prompt,
        temperature: 0.9,
        maxTokens: 30
      }),
      new Promise((_, reject) => 
        setTimeout(() => reject(new Error('LLM timeout')), 3000)
      )
    ]);

    return response.trim();
  } catch (error) {
    console.warn('[DuelCombatAI] LLM trash talk failed, using scripted fallback');
    return null;
  }
}
```

**LLM Configuration:**
- **Model**: TEXT_SMALL (fast, low-cost)
- **Temperature**: 0.9 (creative, varied responses)
- **Max Tokens**: 30 (under 40 characters)
- **Timeout**: 3 seconds (prevents combat blocking)
- **Fallback**: Scripted taunts if LLM fails

### Cooldown System

Prevents trash talk spam:

```typescript
const TRASH_TALK_COOLDOWN_MS = 8000;  // 8 seconds between messages

private fireTrashTalk(
  situation: 'own_low' | 'opponent_low' | 'ambient',
  myHpPct: number,
  oppHpPct: number
): void {
  // Check cooldown
  const now = Date.now();
  if (now - this.lastTrashTalkTime < TRASH_TALK_COOLDOWN_MS) {
    return;
  }

  // Prevent overlapping LLM calls
  if (this.trashTalkInFlight) {
    return;
  }

  this.trashTalkInFlight = true;
  this.lastTrashTalkTime = now;

  // Fire-and-forget (non-blocking)
  this.generateAndSendTrashTalk(situation, myHpPct, oppHpPct)
    .finally(() => {
      this.trashTalkInFlight = false;
    });
}
```

## Weapon Speed Awareness

The combat AI attacks at the correct cadence for the equipped weapon:

```typescript
// From packages/server/src/arena/DuelCombatAI.ts

private async attackOpponent(): Promise<void> {
  const weaponSpeed = this.getWeaponAttackSpeed();
  const ticksSinceLastAttack = this.tickCount - this.lastAttackTick;

  // Only attack if enough ticks have passed for weapon speed
  if (ticksSinceLastAttack >= weaponSpeed) {
    await this.service.attackEntity(this.opponentId);
    this.lastAttackTick = this.tickCount;
    this.stats.attacksLanded++;
  }
}

private getWeaponAttackSpeed(): number {
  const equipment = this.service.getEquipment();
  const weapon = equipment?.weapon;
  
  if (!weapon) return 4;  // Unarmed: 4 ticks (2.4s)
  
  // Get weapon speed from game data
  const weaponData = DataManager.getItem(weapon.id);
  return weaponData?.attackSpeed || 4;
}
```

**Weapon Speeds:**
- Unarmed: 4 ticks (2.4s)
- Dagger: 3 ticks (1.8s)
- Shortsword: 4 ticks (2.4s)
- 2H Sword: 6 ticks (3.6s)
- Scimitar: 4 ticks (2.4s)

private createCombatAIs(): void {

private async tickCombat(): Promise<void> {
  await Promise.all([
    this.combatAI1?.externalTick(),
    this.combatAI2?.externalTick()

private sendChatMessage(agentIndex: number, message: string): void {
  const service = this.services[agentIndex];
  const charId = this.characters[agentIndex].id;
  
  // Send as overhead chat bubble

## Performance Considerations

### Fire-and-Forget Pattern

All trash talk calls are non-blocking:

```typescript
private async generateAndSendTrashTalk(
  situation: string,
  myHpPct: number,
  oppHpPct: number
): Promise<void> {
  // Try LLM generation first
  let message = await this.generateLlmTrashTalk(situation, myHpPct, oppHpPct);

  // Fallback to scripted if LLM fails
  if (!message) {
    message = this.getScriptedTrashTalk(situation);
  }

  // Send message (fire-and-forget)
  if (message && this.sendChatMessage) {
    this.sendChatMessage(message);
    this.stats.trashTalksSent++;
  }
}
```

**Benefits:**
- Never blocks combat tick loop
- LLM timeout (3s) prevents combat delays
- Scripted fallback ensures trash talk always works
- Promise.race() pattern for timeout handling

### Memory Management

- **Threshold Sets**: Track fired thresholds to prevent spam
- **Cooldown Timer**: Single timestamp for all trash talk types
- **In-Flight Flag**: Prevents overlapping LLM calls
- **Stats Object**: Lightweight counter tracking
