## Overview

The Agent Dashboard provides a comprehensive interface for monitoring and controlling AI agents in real-time. Access it at `http://localhost:3333/dashboard` when running with `bun run dev:ai`.

### Goal Panel

Monitor and control agent objectives.

**Features**:
- Current goal description and type
- Progress percentage and elapsed time
- Time estimate to completion
- XP rate (for skill-based goals)
- Lock/unlock goal controls
- **Stop button** - Halt agent and pause goals
- **Resume Auto button** - Resume autonomous behavior
- Recent goals history (last 5 goals)

**Stop/Resume Functionality**:

When you click **Stop**:
1. Agent's current movement is cancelled
2. Active goal is cleared
3. `goalsPaused` flag is set to `true`
4. Agent enters IDLE state
5. `SET_GOAL` actions are blocked
6. Dashboard shows "Goals Paused" state

When you click **Resume Auto**:
1. `goalsPaused` flag is cleared
2. Agent selects new goal on next tick
3. Autonomous behavior resumes

**Paused State Behavior**:
- Agent will NOT auto-select new goals
- Chat commands still work (agent executes them)
- After completing chat command, agent returns to idle
- Pause state persists across reconnections

**API Endpoints**:
```typescript
POST /api/agents/:agentId/goal/stop   // Stop and pause
POST /api/agents/:agentId/goal/resume // Resume autonomous mode
```

## Chat Interface

### Sending Commands

Type commands in the chat input or use the Quick Action Menu:

```
"pick up bronze pickaxe"
"attack goblin"
"go to bank"
"chop tree"
```

**Message Flow**:
```
Dashboard → POST /api/agents/:agentId/message → ElizaOS Runtime →
Action Selection → Game Server → Response → Game Chat (opens automatically)
```

**Auto-Open Chat**: When sending a message from the dashboard, the in-game chat panel opens automatically to show the agent's response.

## Performance Optimizations

### Polling Intervals

All dashboard panels use optimized polling to prevent rate limiting:

| Panel | Interval | Retry Logic |
|-------|----------|-------------|
| Summary Card | 10s | 3 retries, exponential backoff |
| Goal Panel | 10s | 3 retries, exponential backoff |
| Skills Panel | 10s | 3 retries, exponential backoff |
| Activity Panel | 10s | 3 retries, exponential backoff |
| Location Panel | 5-10s | 3 retries, exponential backoff |

### Retry Logic

```typescript
async function fetchWithRetry(url, options, maxRetries = 3) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      const response = await fetch(url, options);
      if (response.ok) return response;
      
      // Don't retry client errors (4xx)
      if (response.status >= 400 && response.status < 500) {
        return response;
      }
    } catch (err) {
      // Network error - retry
    }
    
    // Exponential backoff: 1s, 2s, 4s
    if (attempt < maxRetries - 1) {
      await sleep(1000 * Math.pow(2, attempt));
    }
  }
  throw new Error('Max retries exceeded');
}
```

## Troubleshooting

### Dashboard Not Loading

**Symptoms**: Blank screen or loading spinner

**Fix**: Verify ElizaOS is running:
```bash
bun run dev:ai  # Not just bun run dev
```

### Agent Not Responding

**Symptoms**: Commands sent but no action

**Fix**: Check agent connection status in Summary Card. If offline, restart ElizaOS.

### 429 Rate Limit Errors

**Symptoms**: Dashboard panels showing errors

**Fix**: Rate limiting should be resolved with 10s polling intervals. If still occurring:
1. Check browser console for error details
2. Verify global rate limit (100 req/min) isn't exceeded
3. Close duplicate dashboard tabs

### Goals Not Resuming

**Symptoms**: Agent stuck in idle after clicking Resume Auto

**Fix**: Pause state syncs on reconnection. If agent disconnected:
1. Wait for reconnection (auto-reconnect enabled by default)
2. Pause state will restore from server
3. Click Resume Auto again if needed
