## Overview

The Hyperscape particle system uses GPU instancing and Three.js Shading Language (TSL) to render thousands of particles with minimal CPU overhead. Introduced in PR #877 (February 2026), this system provides a 97% reduction in draw calls and an 80% FPS improvement for fishing spots.

## Architecture

### ParticleManager

Central routing system that dispatches particle events to specialized sub-managers based on resource type:

```typescript
import { ParticleManager } from '@hyperscape/shared';

const particleManager = new ParticleManager(scene);
```

**Responsibilities:**
- Route particle registration/unregistration to appropriate sub-manager
- Track particle ownership by entity ID
- Coordinate per-frame updates across all sub-managers
- Handle resource events from game systems
- Manage lifecycle (creation, updates, disposal)

**Current Sub-Managers:**
- **WaterParticleManager**: Fishing spot effects (splash, bubble, shimmer, ripple)

**Future Sub-Managers:**
- FireParticleManager: Flame and smoke effects
- MagicParticleManager: Spell impact and aura effects
- DustParticleManager: Environmental dust and debris
- BloodParticleManager: Combat hit effects

### WaterParticleManager

GPU-instanced water particle effects for fishing spots using InstancedMesh and TSL shaders.

**Performance Metrics:**
- **Draw Calls**: ~150 → 4 per fishing spot (97% reduction)
- **FPS**: 65-70 → 120 on reference hardware (80% increase)
- **CPU Code**: ~450 lines of animation code eliminated
- **CPU Overhead**: Zero (all animations on GPU)

**Technical Implementation:**

#### InstancedMesh Layers

Four separate InstancedMesh objects for different particle types:

| Layer | Max Instances | Purpose | Lifetime |
|-------|---------------|---------|----------|
| Splash | 96 | Water droplets in parabolic arcs | 0.6-1.2s |
| Bubble | 72 | Rising bubbles with wobble | 1.2-2.5s |
| Shimmer | 72 | Surface sparkles with twinkle | 1.5-3.0s |
| Ripple | 24 | Expanding ring waves | Continuous |

#### InstancedBufferAttributes

Per-particle data stored in GPU buffers:

```typescript
// Particle layers (splash, bubble, shimmer)
spotPos: vec3        // Fishing spot world center
ageLifetime: vec2    // Current age (x), total lifetime (y)
angleRadius: vec2    // Polar angle (x), radial distance (y)
dynamics: vec4       // peakHeight (x), size (y), speed (z), direction (w)

// Ripple layer
spotPos: vec3        // Fishing spot world center
rippleParams: vec2   // Phase offset (x), ripple speed (y)
```

**Vertex Buffer Budget:**
- Particle layers: 7 of 8 max attributes
  - position(1) + uv(1) + instanceMatrix(1) + spotPos(1) + ageLifetime(1) + angleRadius(1) + dynamics(1)
- Ripple layer: 5 of 8 max attributes
  - position(1) + uv(1) + instanceMatrix(1) + spotPos(1) + rippleParams(1)

#### TSL Shader Animations

All particle animations computed on GPU using Three.js Shading Language:

**Splash Particles:**
```typescript
// Parabolic arc trajectory
const arcY = mul(peakHeight, mul(float(4), mul(t, sub(float(1), t))));
const ox = mul(cos(angle), radius);
const oz = mul(sin(angle), radius);
particleCenter = add(spotPos, vec3(ox, add(float(0.08), arcY), oz));

// Snappy fade-in, smooth fade-out
const fadeIn = min(mul(t, float(12)), float(1));
const fadeOut = pow(sub(float(1), t), float(1.2));
material.opacityNode = mul(texAlpha, mul(float(0.9), mul(fadeIn, fadeOut)));
```

**Bubble Particles:**
```typescript
// Rising with lateral wobble
const riseY = mul(t, peakHeight);
const wobbleFreq = mul(direction, float(4.0));
const drift = mul(sin(add(angle, mul(t, wobbleFreq))), radius);
const driftZ = mul(cos(add(angle, mul(t, float(2.5)))), mul(radius, float(0.6)));
particleCenter = add(spotPos, vec3(drift, add(float(0.03), riseY), driftZ));
```

**Shimmer Particles:**
```typescript
// Surface sparkle with fast twinkle
const freq = mul(speed, mul(direction, float(6)));
const wanderX = mul(cos(add(angle, mul(t, freq))), radius);
const wanderZ = mul(sin(add(angle, mul(t, freq))), radius);
particleCenter = add(spotPos, vec3(wanderX, float(0.06), wanderZ));

// Twinkle effect using global time
const twinkle = max(
  float(0),
  mul(
    sin(add(mul(time, float(8)), mul(angle, float(5)))),
    sin(add(mul(time, float(13)), mul(angle, float(3))))
  )
);
```

**Ripple Rings:**
```typescript
// Expanding ring with phase-based scale
const phase = fract(add(mul(time, mul(rippleSpeed, float(0.5))), phaseOffset));
const scale = add(float(0.15), mul(phase, float(1.3)));

// Two-stage fade (early ramp, late decay)
const earlyFade = mul(div(phase, float(0.15)), float(0.55));
const lateFade = mul(
  float(0.55),
  pow(sub(float(1), div(sub(phase, float(0.15)), float(0.85))), float(1.5))
);
const s = step(float(0.15), phase);
const rippleOpacity = mix(earlyFade, lateFade, s);
```

## Usage

### Basic Registration

```typescript
import { ParticleManager } from '@hyperscape/shared';

// Create particle manager (done by ResourceSystem on client)
const particleManager = new ParticleManager(scene);

// Register fishing spot
particleManager.registerSpot({
  entityId: 'fishing-spot-123',
  position: { x: 10, y: 0, z: 20 },
  resourceType: 'fishing_spot',
  resourceId: 'fishing_spot_net'
});
```

### Moving Particles

```typescript
// Update particle position when fishing spot relocates
particleManager.moveSpot(
  'fishing-spot-123',
  'fishing_spot',
  { x: 12, y: 0, z: 22 }
);
```

### Per-Frame Update

```typescript
// Called by ResourceSystem.update()
particleManager.update(deltaTime, camera);
```

### Cleanup

```typescript
// Unregister when entity is destroyed
particleManager.unregisterSpot('fishing-spot-123', 'fishing_spot');

// Dispose all particle managers on system shutdown
particleManager.dispose();
```

## Integration with ResourceSystem

The ParticleManager is created and managed by ResourceSystem on the client:

```typescript
// From packages/shared/src/systems/shared/entities/ResourceSystem.ts

export class ResourceSystem extends SystemBase {
  public particleManager?: ParticleManager;

  start(): void {
    // CLIENT: Create centralized particle hub for all particle effects
    if (!this.world.isServer) {
      const scene = this.world.stage?.scene;
      if (scene) {
        this.particleManager = new ParticleManager(scene as any);

        // Retroactively register any fishing spot entities created before this system started
        const existingEntities = this.world.entities?.getByType?.("resource") || [];
        for (const entity of existingEntities) {
          if (
            entity instanceof ResourceEntity &&
            entity.config?.resourceType === "fishing_spot"
          ) {
            entity.tryRegisterWithParticleManager();
          }
        }
      }

      // Listen for resource events and route them through the particle hub
      this.subscribe(
        EventType.RESOURCE_SPAWNED,
        (data: { id?: string; type?: string; position?: { x: number; y: number; z: number } }) => {
          this.particleManager?.handleResourceEvent(data);
        }
      );
    }
  }

  update(dt: number): void {
    if (this.particleManager) {
      const camera = this.world.camera;
      if (camera) {
        this.particleManager.update(dt, camera);
      }
    }
  }

  destroy(): void {
    if (this.particleManager) {
      this.particleManager.dispose();
      this.particleManager = undefined;
    }
    
    ResourceEntity.disposeSharedResources();
  }
}
```

## Lazy Registration Pattern

ResourceEntity uses a lazy registration pattern to handle timing issues where entities may be created before ResourceSystem starts:

```typescript
// From packages/shared/src/entities/world/ResourceEntity.ts

export class ResourceEntity extends InteractableEntity {
  private _registeredWithParticleManager = false;

  private createFishingSpotVisual(): void {
    // Create the glow indicator (interaction hitbox + distant visibility)
    this.createGlowIndicator();

    // Try to register with centralized particle manager (may not exist yet)
    this.tryRegisterWithParticleManager();

    // Register for frame updates (glow pulse + lazy particle registration)
    this.world.setHot(this, true);
  }

  public tryRegisterWithParticleManager(): boolean {
    if (this._registeredWithParticleManager) return true;

    const pm = this.getParticleManager();
    if (!pm) return false;

    const pos = this.getPosition();
    pm.registerSpot({
      entityId: this.id,
      position: { x: pos.x, y: pos.y, z: pos.z },
      resourceType: this.config.resourceType || "",
      resourceId: this.config.resourceId || "",
    });
    this._registeredWithParticleManager = true;
    return true;
  }

  private getParticleManager(): ParticleManager | undefined {
    const sys = this.world.getSystem("resource") as {
      particleManager?: ParticleManager;
    } | null;
    return sys?.particleManager;
  }

  protected clientUpdate(_deltaTime: number): void {
    super.clientUpdate(_deltaTime);

    // Lazy registration: retry if particle manager wasn't ready during createFishingSpotVisual
    if (
      !this._registeredWithParticleManager &&
      this.config.resourceType === "fishing_spot"
    ) {
      if (this.tryRegisterWithParticleManager()) {
        console.log(`[FishingSpot] Late registration succeeded for ${this.id}`);
      }
    }

    // Organic glow pulse — two frequencies layered for natural breathing
    if (this.glowMesh) {
      const now = Date.now();
      const slow = Math.sin(now * 0.0015) * 0.04;
      const fast = Math.sin(now * 0.004 + 1.3) * 0.02;
      const pulse = 0.18 + slow + fast;
      (this.glowMesh.material as THREE.MeshBasicMaterial).opacity = pulse;
    }
  }

  destroy(): void {
    // Clean up fishing spot resources
    if (this.config.resourceType === "fishing_spot") {
      // Unregister from centralized particle manager
      if (this._registeredWithParticleManager) {
        const pm = this.getParticleManager();
        if (pm) {
          pm.unregisterSpot(this.id, this.config.resourceType || "");
        }
        this._registeredWithParticleManager = false;
      }

      // Unregister from frame updates (glow pulse)
      this.world.setHot(this, false);
    }

    super.destroy();
  }
}
```

### 2. Add to ParticleManager

Update `packages/shared/src/entities/managers/particleManager/ParticleManager.ts`:

```typescript
import { WaterParticleManager } from "./WaterParticleManager";
import { MagicParticleManager } from "./MagicParticleManager";

export class ParticleManager {
  private waterManager: WaterParticleManager;
  private magicManager: MagicParticleManager;

  constructor(scene: THREE.Scene) {
    this.waterManager = new WaterParticleManager(scene);
    this.magicManager = new MagicParticleManager(scene);
    console.log("[ParticleManager] Initialized with WaterParticleManager, MagicParticleManager");
  }

  registerSpot(config: ParticleSpotConfig): void {
    if (this.isWaterType(config.resourceType)) {
      this.waterManager.registerSpot({ /* ... */ });
      return;
    }
    if (this.isMagicType(config.resourceType)) {
      this.magicManager.registerSpot({ /* ... */ });
      return;
    }
  }

  unregisterSpot(entityId: string, resourceType: string): void {
    if (this.isWaterType(resourceType)) {
      this.waterManager.unregisterSpot(entityId);
      return;
    }
    if (this.isMagicType(resourceType)) {
      this.magicManager.unregisterSpot(entityId);
      return;
    }
  }

  moveSpot(
    entityId: string,
    resourceType: string,
    newPos: { x: number; y: number; z: number }
  ): void {
    if (this.isWaterType(resourceType)) {
      this.waterManager.moveSpot(entityId, newPos);
      return;
    }
    if (this.isMagicType(resourceType)) {
      this.magicManager.moveSpot(entityId, newPos);
      return;
    }
  }

  update(dt: number, camera: THREE.Camera): void {
    this.waterManager.update(dt, camera);
    this.magicManager.update(dt, camera);
  }

  dispose(): void {
    this.waterManager.dispose();
    this.magicManager.dispose();
    console.log("[ParticleManager] Disposed all particle managers");
  }

  private isWaterType(resourceType: string): boolean {
    return resourceType === "fishing_spot";
  }

  private isMagicType(resourceType: string): boolean {
    return resourceType === "magic_altar" || resourceType === "magic_portal";
  }
}
```

## Performance Considerations

### Memory Management

- **Pool-Based Allocation**: Pre-allocated particle slots prevent runtime allocations
- **Typed Arrays**: Float32Array and Uint8Array for efficient GPU uploads
- **Shared Geometry**: Single geometry instance shared across all particles in a layer
- **Texture Caching**: DataTextures cached and reused across particle systems

### GPU Optimization

- **Instanced Rendering**: Single draw call per particle layer
- **Billboard Computation**: Camera vectors updated once per frame, not per particle
- **Attribute Updates**: Only mark attributes as needing update when data changes
- **Dirty Flags**: Track which attributes need GPU upload to minimize bandwidth

### CPU Optimization

- **Zero Animation Code**: All particle motion computed on GPU
- **Minimal State Tracking**: Only essential data stored per particle
- **Lazy Registration**: Entities retry registration instead of blocking
- **Fire-and-Forget**: Particle updates don't block game logic
