#### Ground Item Bbox Snapping (PR #718)

- **Automatic Terrain Alignment**: Items and fires snap to ground using bounding box
  - Calculates `bbox.min.y` and offsets mesh position
  - Compensates for GroundItemSystem's 0.2m terrain offset
  - Named constant: `GROUND_ITEM_TERRAIN_OFFSET = 0.2`
  - Applies to all ground items and fire models
- **Grounded Items**: Items with `groundOffset ≤ 0` use bbox snapping
  - No floating/spinning animation for grounded items
  - Prevents clipping through terrain
  - Configurable per-item via manifest
- **Item Manifest Fields**:
  - `modelScale`: Override default 0.3 scale for ground items
  - `groundOffset`: Control Y positioning (≤0 = grounded, >0 = floating, undefined = 0.5 default)
- **Network Sync**: modelScale and groundOffset serialized to clients
- **Documentation**: Clarified groundOffset behavior with bullet-point format
