## Overview

The `@hyperscape/client` package is the web game client:

- Vite for fast builds with HMR
- React 19 UI framework
- Three.js 3D rendering
- Capacitor for iOS/Android mobile builds
- Privy authentication
- Farcaster miniapp SDK

## UI Architecture

The client uses a clear separation between reusable UI primitives and game-specific code:

### UI Design System (`src/ui/`)

Pure, reusable UI components and systems:

```typescript
// From packages/client/src/ui/
components/               // Base UI primitives
  Window.tsx             // Draggable, resizable windows
  TabBar.tsx             // Tab navigation
  DragOverlay.tsx        // Drag preview overlay
  Portal.tsx             // React portal for overlays
  MenuButton.tsx         // Menu buttons
  Slider.tsx             // Range sliders
  ToggleSwitch.tsx       // Toggle switches
  ItemSlot.tsx           // Item slot component
  // ... and more

core/                    // Core UI systems
  drag/                  // Drag-and-drop system (@dnd-kit integration)
  edit/                  // Edit mode (L key to unlock)
  notifications/         // Notification system
  presets/               // Layout presets and cloud sync
  responsive/            // Breakpoint and mobile detection
  tabs/                  // Tab management
  tooltip/               # Progressive tooltips
  virtual/               # Virtual scrolling
  window/                # Window management

stores/                  # UI state management (Zustand)
  windowStore.ts         # Window positions and state
  dragStore.ts           # Drag-and-drop state
  editStore.ts           # Edit mode state
  anchorUtils.ts         # Anchor-based positioning utilities
  // ... and more

theme/                   # Theme system
  themes.ts              # Color themes
  animations.ts          # Animation presets
```

### HUD Components

- Health/Constitution display
- Combat status indicators
- Skills panel with XP progress
- 28-slot inventory grid
- Equipment slots display
- Bank interface (unlimited storage)
- Chat window
- Minimap with compass

### Game Components

- Three.js 3D renderer
- Camera controller (third-person, click-to-move)
- Input handler (WASD movement, click actions)
- Entity renderers (players, mobs, items)
- VRM avatar display with emotes

## Running

### Development

```bash
bun run dev:client    # Vite dev server with HMR
```

Opens at [http://localhost:3333](http://localhost:3333)

### Production Build

```bash
cd packages/client
bun run build         # Build to dist/
bun run preview       # Preview production build
```

## Mobile Builds

### iOS

Requires macOS with Xcode installed.

```bash
bun run ios           # Build and open Xcode
bun run ios:dev       # Sync and open (no rebuild)
bun run ios:build     # Production build
```

### Android

Requires Android Studio installed.

```bash
bun run android       # Build and open Android Studio
bun run android:dev   # Sync and open (no rebuild)
bun run android:build # Production build
```

### Capacitor Sync

```bash
bun run cap:sync          # Sync both platforms
bun run cap:sync:ios      # iOS only
bun run cap:sync:android  # Android only
```
