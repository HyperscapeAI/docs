## Overview

The `@hyperscape/client` package is the web game client:

- Vite for fast builds with HMR
- React 19 UI framework
- Three.js 3D rendering
- Capacitor for iOS/Android mobile builds
- Privy authentication
- Farcaster miniapp SDK

### Drag-and-Drop System

The UI uses `@dnd-kit` for accessible drag-and-drop:

```typescript
// From packages/client/src/ui/core/drag/
import { DndProvider, useDraggable, useDroppable } from '@/ui';

// Draggable item
const { attributes, listeners, setNodeRef } = useDraggable({
  id: 'item-123',
  data: { type: 'inventory', itemId: 'bronze_sword' },
});

// Drop zone
const { setNodeRef: setDropRef, isOver } = useDroppable({
  id: 'equipment-weapon',
});
```

**Features:**
- Keyboard and pointer support for accessibility
- Collision detection algorithms
- Drag modifiers (snap to grid, constrain to axis)
- Composable drag overlay
- Touch support for mobile

### Window Management

Windows use anchor-based positioning for responsive scaling:

```typescript
// From packages/client/src/ui/stores/windowStore.ts
export type WindowAnchor =
  | "top-left" | "top-center" | "top-right"
  | "center-left" | "center" | "center-right"
  | "bottom-left" | "bottom-center" | "bottom-right";

// Windows maintain position relative to viewport anchor
// Ensures proper scaling across different screen sizes
```

**Window Features:**
- Draggable and resizable
- Anchor-based positioning (Unity/Unreal-style)
- Responsive scaling for mobile ↔ desktop transitions
- Tab combining (drag tabs between windows)
- Layout presets and sharing
- Edit mode with alignment guides
- Collision visualization
- Grid snapping

## Running

### Development

```bash
bun run dev:client    # Vite dev server with HMR
```

Opens at [http://localhost:3333](http://localhost:3333)

### Production Build

```bash
cd packages/client
bun run build         # Build to dist/
bun run preview       # Preview production build
```

## Mobile Builds

### iOS

Requires macOS with Xcode installed.

```bash
bun run ios           # Build and open Xcode
bun run ios:dev       # Sync and open (no rebuild)
bun run ios:build     # Production build
```

### Android

Requires Android Studio installed.

```bash
bun run android       # Build and open Android Studio
bun run android:dev   # Sync and open (no rebuild)
bun run android:build # Production build
```

### Capacitor Sync

```bash
bun run cap:sync          # Sync both platforms
bun run cap:sync:ios      # iOS only
bun run cap:sync:android  # Android only
```
