## Overview

The `@hyperscape/client` package is the web game client:

- Vite for fast builds with HMR
- React 19 UI framework
- Three.js 3D rendering
- Capacitor for iOS/Android mobile builds
- Privy authentication
- Farcaster miniapp SDK

### HUD Components

- Health/Constitution display
- Combat status indicators
- Skills panel with XP progress
- 28-slot inventory grid
- Equipment slots display

### Game Components

- Three.js 3D renderer
- Camera controller (third-person, click-to-move)
- Input handler (WASD movement, click actions)
- Entity renderers (players, mobs, items)
- VRM avatar display with emotes
- Skill Guide Panel (OSRS-style unlock progression viewer)

**Skill Guide Panel** (`SkillGuidePanel.tsx`):

Opens when clicking any skill in the Skills Panel. Displays all unlocks for that skill with:
- Current level and progress (X/Y unlocked)
- Next unlock highlighting with countdown
- Visual distinction (green checkmark for unlocked, lock icon for locked)
- Type badges (item/ability)
- Loading state while fetching from server
- Smooth animations and OSRS-themed styling

## Environment Variables

### Development

```bash
# Required for persistent authentication
PUBLIC_PRIVY_APP_ID=your-privy-app-id

# Server URLs (defaults to localhost)
PUBLIC_API_URL=http://localhost:5555
PUBLIC_WS_URL=ws://localhost:5555/ws
PUBLIC_CDN_URL=http://localhost:8080
```

### Production (Cloudflare Pages)

```bash
# Required
PUBLIC_PRIVY_APP_ID=your-privy-app-id

# Production endpoints
PUBLIC_API_URL=https://hyperscape-production.up.railway.app
PUBLIC_WS_URL=wss://hyperscape-production.up.railway.app/ws
PUBLIC_CDN_URL=https://assets.hyperscape.club
PUBLIC_APP_URL=https://hyperscape.club

# Optional
PUBLIC_ENABLE_FARCASTER=true
DEBUG_RPG=0
```

<Warning>
`PUBLIC_PRIVY_APP_ID` must match the `PRIVY_APP_ID` set in the server environment. Mismatched IDs will cause authentication failures.
</Warning>

<Info>
All `PUBLIC_*` variables are exposed to the browser. Never put secrets in client environment variables.
</Info>

## Running

### Development

```bash
bun run dev:client    # Vite dev server with HMR
```

Opens at [http://localhost:3333](http://localhost:3333)

### Production Build

```bash
cd packages/client
bun run build         # Build to dist/
bun run preview       # Preview production build
```

## Mobile Builds

### iOS

Requires macOS with Xcode installed.

```bash
bun run ios           # Build and open Xcode
bun run ios:dev       # Sync and open (no rebuild)
bun run ios:build     # Production build
```

### Android

Requires Android Studio installed.

```bash
bun run android       # Build and open Android Studio
bun run android:dev   # Sync and open (no rebuild)
bun run android:build # Production build
```

### Capacitor Sync

```bash
bun run cap:sync          # Sync both platforms
bun run cap:sync:ios      # iOS only
bun run cap:sync:android  # Android only
```

## Deployment

### Cloudflare Pages (Production)

The client is deployed to Cloudflare Pages with automatic GitHub integration.

**Production domains:**
- Primary: https://hyperscape.club
- Pages: https://hyperscape.pages.dev
- Preview: `<branch>.hyperscape.pages.dev`

**Build configuration:**
```
Framework preset: None (Vite)
Build command: cd packages/client && bun run build
Build output: packages/client/dist
Root directory: / (repository root)
```

**Environment variables** (set in Pages dashboard):
```bash
PUBLIC_PRIVY_APP_ID=<from-privy-dashboard>
PUBLIC_API_URL=https://hyperscape-production.up.railway.app
PUBLIC_WS_URL=wss://hyperscape-production.up.railway.app/ws
PUBLIC_CDN_URL=https://assets.hyperscape.club
PUBLIC_APP_URL=https://hyperscape.club
```

**Manual deployment:**
```bash
# Via Cloudflare Pages dashboard
# Or via wrangler CLI:
cd packages/client
bunx wrangler pages deploy dist
```

### Alternative: Vercel

```bash
# Import packages/client directory to Vercel
# Set build command: bun run build
# Set output directory: dist
# Add PUBLIC_* environment variables
```
