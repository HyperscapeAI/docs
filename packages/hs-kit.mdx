## Overview

`hs-kit` is a custom React UI toolkit designed specifically for game interfaces. It provides draggable windows, tab management, edit mode, and a complete theme system with OSRS-inspired styling.

**Package:** `packages/hs-kit/`  
**Exports:** 594 components, hooks, and utilities

<Info>
  hs-kit replaces the legacy `@dnd-kit` dependency with a lightweight, game-optimized drag-and-drop system.
</Info>

---

## Core Features

### Window Management

Draggable, resizable windows with z-index management:

```typescript
import { useWindowManager, Window } from "hs-kit";

function MyPanel() {
  const { windows, createWindow, closeWindow } = useWindowManager();
  
  return (
    <Window
      id="inventory"
      title="Inventory"
      defaultPosition={{ x: 100, y: 100 }}
      defaultSize={{ width: 400, height: 500 }}
      resizable
      onClose={() => closeWindow("inventory")}
    >
      <div>Inventory contents...</div>
    </Window>
  );
}
```

**Features:**
- Drag to move (click title bar)
- Resize handles (8 directions)
- Grid snapping in edit mode
- Z-index auto-management (click to focus)
- Layout persistence via localStorage

### Tab System

Windows can contain multiple tabs with split/merge functionality:

```typescript
import { useTabs, TabContainer } from "hs-kit";

function TabbedWindow() {
  const { tabs, activeTab, setActiveTab, splitTab, mergeTab } = useTabs();
  
  return (
    <TabContainer
      tabs={tabs}
      activeTab={activeTab}
      onTabChange={setActiveTab}
      onTabSplit={splitTab}
      onTabMerge={mergeTab}
      overflow="scroll" // or "dropdown"
    >
      {/* Tab content */}
    </TabContainer>
  );
}
```

**Features:**
- Horizontal tab bar with overflow handling
- Right-click context menu (split, merge, close)
- Drag tabs between windows
- Tab overflow: scroll or dropdown

### Edit Mode

Hold **L key** to unlock edit mode:

```typescript
import { useEditMode, EditModeProvider } from "hs-kit";

function App() {
  return (
    <EditModeProvider>
      <GameInterface />
    </EditModeProvider>
  );
}

function GameInterface() {
  const { isEditMode, isLocked } = useEditMode();
  
  return (
    <div>
      {isEditMode && <GridOverlay />}
      {isEditMode && <AlignmentGuides />}
      {/* Windows are draggable/resizable only in edit mode */}
    </div>
  );
}
```

**Features:**
- Hold L to unlock (prevents accidental drags during gameplay)
- Grid overlay for alignment
- Collision visualization
- Alignment guides between windows
- Snap-to-grid modifier

### Drag & Drop System

Custom drag-and-drop implementation optimized for games:

```typescript
import { 
  DndProvider, 
  useDraggable, 
  useDroppable,
  ComposableDragOverlay 
} from "hs-kit";

function DraggableItem({ id, data }) {
  const { attributes, listeners, setNodeRef, isDragging } = useDraggable({
    id,
    data: { type: "item", itemId: data.itemId }
  });
  
  return (
    <div ref={setNodeRef} {...listeners} {...attributes}>
      {/* Item content */}
    </div>
  );
}

function DropZone({ id }) {
  const { setNodeRef, isOver } = useDroppable({ id });
  
  return (
    <div ref={setNodeRef} style={{ background: isOver ? "green" : "gray" }}>
      {/* Drop zone content */}
    </div>
  );
}

function App() {
  return (
    <DndProvider
      collisionDetection={pointerWithin}
      onDragStart={handleDragStart}
      onDragEnd={handleDragEnd}
    >
      <DraggableItem />
      <DropZone />
      <ComposableDragOverlay>
        {/* Drag preview */}
      </ComposableDragOverlay>
    </DndProvider>
  );
}
```

**Collision Detection:**
- `closestCenter` - Nearest drop zone by center point
- `rectIntersection` - Overlapping rectangles
- `pointerWithin` - Pointer inside drop zone

**Modifiers:**
- `restrictToWindow` - Keep draggable within viewport
- `snapToGridModifier` - Snap to grid in edit mode
- `composeModifiers` - Combine multiple modifiers

### Theme System

Customizable theme with design tokens:

```typescript

function ThemedComponent() {

```

**Theme Structure:**


## Layout Presets

Save and restore window layouts:

```typescript
import { usePresets, usePresetHotkeys } from "hs-kit";

function LayoutManager() {
  const { 
    presets, 
    activePreset, 
    savePreset, 
    loadPreset, 
    deletePreset 
  } = usePresets();
  
  // Hotkeys: Ctrl+1-5 to load presets
  usePresetHotkeys(presets, loadPreset);
  
  return (
    <div>
      <button onClick={() => savePreset("Combat Layout")}>
        Save Layout
      </button>
      {presets.map(preset => (
        <button key={preset.id} onClick={() => loadPreset(preset.id)}>
          {preset.name}
        </button>
      ))}
    </div>
  );
}
```

**Storage:**
- **Local:** `localStorage` (per-browser)
- **Cloud:** Optional server sync (requires backend routes)

## Performance Optimizations

### Zero-Allocation Hot Paths

hs-kit avoids allocations in frequently-called code:

```typescript
// Pre-allocated buffers for drag calculations
private readonly _dragOffset = { x: 0, y: 0 };
private readonly _position = { x: 0, y: 0 };

// Reuse instead of creating new objects
updatePosition(x: number, y: number) {
  this._position.x = x;
  this._position.y = y;
  return this._position; // Return reference, not new object
}
```

### Memoization

Heavy components use React.memo and useMemo:

```typescript
import { useMemo } from "react";

const sortedItems = useMemo(() => {
  return items.sort((a, b) => a.slot - b.slot);
}, [items]);
```

### Virtual Scrolling

For long lists (chat, inventory):

```typescript
import { useVirtualScroll } from "hs-kit";

function LongList({ items }) {
  const { visibleItems, scrollProps } = useVirtualScroll({
    items,
    itemHeight: 40,
    overscan: 5
  });
  
  return (
    <div {...scrollProps}>
      {visibleItems.map(item => <Item key={item.id} {...item} />)}
    </div>
  );
}
```

## Examples

### Complete Window with Tabs

```typescript
import { 
  Window, 
  TabContainer, 
  useWindowManager, 
  useTabs,
  useThemeStore 
} from "hs-kit";

function SkillsWindow() {
  const theme = useThemeStore((s) => s.theme);
  const { closeWindow } = useWindowManager();
  const { tabs, activeTab, setActiveTab } = useTabs({
    tabs: [
      { id: "combat", label: "Combat", icon: "⚔️" },
      { id: "gathering", label: "Gathering", icon: "🪓" },
      { id: "artisan", label: "Artisan", icon: "🔨" }
    ]
  });
  
  return (
    <Window
      id="skills"
      title="Skills"
      defaultPosition={{ x: 200, y: 100 }}
      defaultSize={{ width: 450, height: 550 }}
      resizable
      onClose={() => closeWindow("skills")}
    >
      <TabContainer
        tabs={tabs}
        activeTab={activeTab}
        onTabChange={setActiveTab}
      >
        {activeTab === "combat" && <CombatSkills />}
        {activeTab === "gathering" && <GatheringSkills />}
        {activeTab === "artisan" && <ArtisanSkills />}
      </TabContainer>
    </Window>
  );
}
```

### Drag & Drop Inventory

```typescript
import { 
  DndProvider, 
  useDraggable, 
  useDroppable,
  pointerWithin 
} from "hs-kit";

function InventorySlot({ item, slot }) {
  const { attributes, listeners, setNodeRef, isDragging } = useDraggable({
    id: `inventory-${slot}`,
    data: { type: "inventory", slot, itemId: item?.id }
  });
  
  return (
    <div 
      ref={setNodeRef} 
      {...listeners} 
      {...attributes}
      style={{ opacity: isDragging ? 0.5 : 1 }}
    >
      {item && <ItemIcon item={item} />}
    </div>
  );

  const { setNodeRef, isOver } = useDroppable({
    id: `equipment-${slot}`
  });
  
  return (

      ref={setNodeRef}
      style={{ background: isOver ? "green" : "gray" }}
    >
      {/* Equipment slot */}
    </div>
  );
}

      collisionDetection={pointerWithin}
      onDragEnd={handleDragEnd}
```

## Performance Guidelines

### Do's ✅

- Use `React.memo` for heavy components
- Use `useMemo` for expensive calculations
- Use `useCallback` for event handlers passed to children
- Debounce localStorage writes (500ms)
- Use virtual scrolling for lists >100 items

### Don'ts ❌

- Don't create new objects in render (use refs)
- Don't use inline styles for static values
- Don't re-render entire window on drag (use transforms)
- Don't save layout on every pixel moved (debounce)
